## 为什么重要
当题目要求“左侧/右侧最近的更大/更小元素”或“每个大小为 $k$ 的窗口的最大值”时，暴力解是 $O(n^2)$，预期答案是 $O(n)$ 的单调栈或双端队列。它们是中等偏难题的常客（柱状图最大矩形、接雨水、滑动窗口最大值）。“下一个更大元素”的基本思路出现在“栈与队列”一课；本课更进一步。

## 概念
**单调栈**：在栈中保存下标，其对应的值始终递增（或递减）。当新元素破坏顺序时，不断弹出直到顺序恢复；每次弹出就是得知**被弹出元素答案**的时刻（它的下一个更大/更小元素就是当前下标）。每个下标入栈、出栈各一次，所以是 $O(n)$。

**单调双端队列**（滑动窗口最大/最小值）：保存下标，其值从队首到队尾递减。
1. 当 `a[back] <= a[i]` 时从队尾弹出（`a[i]` 更新且不小于它们，它们不可能再成为窗口最大值）。
2. 把 `i` 压入队尾。
3. 如果队首下标已离开窗口（`front <= i - k`），从队首弹出。
4. 队首就是窗口最大值。

每个下标进出一次，总共 $O(n)$，而不是 $O(nk)$。

**方向怎么选？**

| 想要 | 栈的顺序（从底到顶） | 弹出条件 |
|---|---|---|
| 右侧下一个更大 | 递减 | `a[i] > a[top]` |
| 右侧下一个更小 | 递增 | `a[i] < a[top]` |
| 左侧上一个更大/更小 | 同一个栈；在压入**之前**读取新的栈顶 | |

**贡献法。** 对“所有子数组最小/最大值之和”，为每个元素计算它作为最小值的范围：`left` = 到上一个更小元素的距离，`right` = 到下一个更小或相等元素的距离。它贡献 `a[i] * left * right`。一侧用严格比较、另一侧用非严格比较，这样相等的值不会被重复计算。

**陷阱。** 存值而不是下标（丢失距离信息）。结束时没有清空栈（用哨兵或第二个循环）。宽度的差一错误：被弹出柱子的宽度是 `i - 新栈顶 - 1`，栈为空时是 `i`。

## 示例讲解
**柱状图中最大的矩形**，`h = [2, 1, 5, 6, 2, 3]`。保存高度递增的下标；当 `h[i]` 更小时，弹出并计算以被弹出柱子为高的矩形。宽度 = `i - (新栈顶) - 1`，栈为空时为 `i`。

```text
i=0 h=2  push                      stack [0]
i=1 h=1  pop 0 (h=2): width=1 area=2   push        stack [1]
i=2 h=5  push                      stack [1,2]
i=3 h=6  push                      stack [1,2,3]
i=4 h=2  pop 3 (h=6): width=4-2-1=1 area=6
         pop 2 (h=5): width=4-1-1=2 area=10  <- best
         push                      stack [1,4]
i=5 h=3  push                      stack [1,4,5]
end(i=6) pop 5 (h=3): width=6-4-1=1 area=3
         pop 4 (h=2): width=6-1-1=4 area=8
         pop 1 (h=1): stack empty, width=6 area=6
```

答案 **10**（高度 5 和 6 的两根柱子，宽度 2），一趟扫描：6 次入栈、6 次出栈。

> [!TIP] 面试技巧
> - 先说明不变式（“栈是递减的”）以及一次弹出意味着什么（“我刚刚找到了这个元素的答案”）。
> - 论证均摊：每个下标入栈、出栈各一次，所以嵌套循环仍是 O(n)。
> - 最大矩形和接雨水是最常见的两个追问；它们也能用双指针或前缀数组解决，可以提一下替代方案。
> - 有意识地处理相等值（严格 vs 非严格），并用全相等数组测试。
