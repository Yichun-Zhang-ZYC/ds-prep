## 为什么重要
前缀和经过 $O(n)$ 预处理后，可以 $O(1)$ 回答任意区间的和；结合哈希表，只需一趟扫描就能解决“统计和为 $k$ 的子数组个数”。差分数组则是其逆操作：每次区间更新只需 $O(1)$。它们一起能替代大量数组题中的嵌套循环。基本的前缀和思想在“数组与字符串”一课中介绍过；这里作进一步扩展。

## 概念
**前缀和。** 令 $P_0 = 0$，$P_{i+1} = P_i + a_i$。则 $\sum_{l}^{r} a = P_{r+1} - P_l$（闭区间 $l..r$）。构建 $O(n)$，每次查询 $O(1)$。

**前缀和 + 哈希表（和为 $k$ 的子数组）。** 子数组 $(l, r]$ 的和恰为 $k$，当且仅当 $P_r - P_l = k$。从左到右扫描并维护映射 `count[prefix]`；在每个 $r$ 处累加 `count[P_r - k]`，然后记录 $P_r$。用 `count[0] = 1` 作为初值，以覆盖从下标 0 开始的子数组。时间和空间均为 $O(n)$，并且在有负数时仍然成立（滑动窗口则不行）。

变体：和能被 $k$ 整除（键 = `P % k`）、0 和 1 个数相同（把 0 映射为 $-1$，找和为 0 的子数组）、和为 $k$ 的最长子数组（保存每个前缀的**首次**下标）。

**二维前缀和。** $P[i+1][j+1] = a[i][j] + P[i][j+1] + P[i+1][j] - P[i][j]$。闭矩形 $(r_1,c_1)..(r_2,c_2)$：
$$S = P[r_2+1][c_2+1] - P[r_1][c_2+1] - P[r_2+1][c_1] + P[r_1][c_1]$$
（容斥原理）。

**差分数组。** 要给 $[l, r]$ 的每个元素加 $v$：`d[l] += v` 且 `d[r+1] -= v`。所有更新结束后，对 `d` 求前缀和即得最终数组。每次更新 $O(1)$，最终化 $O(n)$；总共 $O(n + q)$，而朴素做法是 $O(nq)$。用于航班预订、拼车和扫描线的事件计数。

**关系。** 前缀和与差分互为逆运算：对数组先差分再求前缀和会还原原数组。

**陷阱。** 长度为 $n+1$ 的 `P` 与长度为 $n$ 的 `a` 之间的差一错误。忘记 `count[0] = 1`。存在负数时使用滑动窗口。仅适用于静态数据：前缀数组不支持单点更新（需要的话用树状数组）。

## 示例讲解
**和为 k 的子数组**，`nums = [3, 4, 7, 2, -3, 1, 4, 2]`，`k = 7`。前缀和 $P$ = `[0, 3, 7, 14, 16, 13, 14, 18, 20]`。每一步先累加 `count[P - 7]`，再记录 $P$。

```text
P    need(P-7)  count[need]  total   subarray found
3    -4         0            0
7    0          1            1       [3,4]
14   7          1            2       [7]
16   9          0            2
13   6          0            2
14   7          1            3       [7,2,-3,1]
18   11         0            3
20   13         1            4       [1,4,2]
```

一趟扫描得到答案 **4**（初值 `count[0]=1` 产生了 `[3,4]`）。

**差分数组**，$n=5$ 个 0，更新 `(1,3,+2)`、`(2,4,+3)`、`(0,1,-1)`：`d = [-1, 2, 4, 0, -2, -3]`，求前缀和得 `[-1, 1, 5, 5, 3]`。

> [!TIP] 面试技巧
> - 一看到“统计和为 k 的子数组”且允许负数，立刻说“前缀和 + 哈希表”。
> - 明确定义 `P[0] = 0` 并说明区间是否闭合；大多数 bug 是差一错误。
> - 说明权衡：仅适用于静态数据；若查询之间有更新，用树状数组/线段树。
> - “很多区间更新，最后只读一次”的答案就是差分数组。
