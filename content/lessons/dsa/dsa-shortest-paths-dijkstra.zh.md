## 为什么重要
带权最短路径是最常见的中等偏难图论题之一：网络延迟、最便宜路线、最小体力消耗路径。BFS 只在每条边代价相同时有效；一旦出现权重，预期的工具就是 Dijkstra，面试官会追问它的不变式以及负权边的限制。基础组件见“图”和“堆”两课。

## 概念
**Dijkstra 算法**用于求图中从源点到所有节点的最短距离，要求边权**非负**。

**不变式。** 当一个节点以距离 $d$ 从最小堆中弹出时，$d$ 就是最终值：任何其他路线都必须通过一条边离开“已确定”集合，而权重 $\ge 0$，所以不可能更短。负权边会破坏这一点（后面的负权边可能缩短已确定的节点）。

**算法**
1. `dist[src] = 0`，其余为 $\infty$；堆中放入 `(0, src)`。
2. 弹出 `(d, u)`。如果 `d > dist[u]`，它是**过期**条目；跳过（惰性删除，因为 `heapq` 没有 decrease-key）。
3. 对每条边 `(u, v, w)`：如果 `d + w < dist[v]`，设置 `dist[v] = d + w`，压入 `(dist[v], v)`，并可选地记录 `parent[v] = u`。

**复杂度**：二叉堆下为 $O((V + E) \log V)$（每条边至多引起一次压入）。空间 $O(V + E)$。路径还原：从目标沿 `parent` 回溯。

**如何选择算法**

| 情况 | 使用 |
|---|---|
| 无权 / 权重相同 | BFS，$O(V+E)$ |
| 权重只有 0 或 1 | 使用双端队列的 0-1 BFS |
| 非负权重 | Dijkstra |
| 有负权边，或“最多 $k$ 条边” | Bellman-Ford，$O(VE)$ |
| 有向无环图 | 按拓扑序松弛，$O(V+E)$ |
| 全源最短路，$V$ 较小 | Floyd-Warshall，$O(V^3)$ |

**变体**：最小化路径上**最大**边（最小体力消耗）时，用 `max(d, w)` 代替 `d + w`；带节点代价的网格最短路；多源（把所有源点以距离 0 压入）；带状态扩展的节点 `(node, stops_left)`。

**陷阱。** 忘记过期检查（仍然正确但更慢）、在有负权重时使用它、把不可达节点（`inf`）当作有效答案，以及有向图和无向图的邻接表构建错误。

## 示例讲解
有向图，源点 `A`。边：`A->B 4`、`A->C 1`、`C->B 2`、`B->D 1`、`C->D 5`、`D->E 3`。

```text
pop (0,A)  relax B=4, C=1                   dist A0 B4 C1
pop (1,C)  relax B=min(4,1+2)=3, D=1+5=6    dist A0 B3 C1 D6
pop (3,B)  relax D=min(6,3+1)=4             dist A0 B3 C1 D4
pop (4,B)  stale (4 > 3): skip
pop (4,D)  relax E=4+3=7                    dist ... D4 E7
pop (6,D)  stale: skip
pop (7,E)  done
```

最终距离：**A0, B3, C1, D4, E7**。通过 parent 得到到 `E` 的最短路径：`A -> C -> B -> D -> E`，代价 $1+2+1+3 = 7$。看起来直接的 `A -> B`（4）比经过 `C`（3）更差，按边数计的 BFS 会漏掉这一点。

> [!TIP] 面试技巧
> - 编码前先说明不变式和权重非负的要求；这是常见的追问陷阱。
> - 提到惰性删除，以及 `heapq` 为何需要它（没有 decrease-key）。
> - 被问到负权时，说出 Bellman-Ford（$O(VE)$）和负环检测；有向无环图则用拓扑序松弛。
> - 始终显式处理不可达节点（`inf` 或 -1）和 `src == dst` 的情况。
