## 为什么重要
网格、依赖关系、社交网络、单词接龙和课程安排其实都是图。面试官希望你能正确选择 BFS 或 DFS，记录已访问的节点，检测环，并给出 $O(V + E)$ 的复杂度。

## 概念
**表示方法**：**邻接表**（`dict[node] -> list[neighbors]`）空间 $O(V + E)$，是默认选择；邻接矩阵需要 $O(V^2)$，适合稠密图。网格是隐式图：邻居是上下左右 4 个（或 8 个）相邻格子。

**BFS**（队列）：按边数逐层探索。它能求出**无权图中的最短路径**。节点要在**入队时**标记为已访问，否则会被重复入队。时间 $O(V + E)$，空间 $O(V)$。

**DFS**（递归或栈）：先走到最深处。用于连通分量、洪水填充、路径是否存在、环检测和拓扑序。时间 $O(V + E)$，空间 $O(V)$（调用栈深度可达 $V$，所以输入很大时在 Python 中应使用显式栈）。

**连通分量 / 岛屿**：遍历所有节点，从每个未访问的节点开始 BFS/DFS，统计启动的次数。

**环检测**：无向图中，遇到一个已访问且不是父节点的邻居；有向图中，用三种颜色的 DFS（未访问 / 在当前路径上 / 已完成），或者看 Kahn 算法是否有节点未被处理。

**拓扑排序**（仅适用于 DAG）：使每条边 $u \to v$ 中 $u$ 排在 $v$ 之前的顺序。
- **Kahn 算法**：计算入度，把入度为 0 的节点入队，反复弹出一个节点，加入顺序，并减少其邻居的入度。如果顺序中的节点少于 $V$ 个，则存在环。$O(V + E)$。
- **DFS**：在一个节点的所有后代都处理完之后再加入该节点，最后反转。

**带权最短路径**：Dijkstra（非负权重，堆，$O((V+E)\log V)$），Bellman-Ford（含负边，$O(VE)$）。有权重时直接用 BFS 是错误的。

## 示例讲解
4 门课程，先修关系 `[(0,1), (0,2), (1,3), (2,3)]`（表示 `0` 必须排在 `1` 之前，依此类推）。Kahn 算法：
1. 入度：`0:0, 1:1, 2:1, 3:2`。队列 `[0]`。
2. 弹出 0，顺序 `[0]`。把 1 和 2 的入度减到 0：队列 `[1, 2]`。
3. 弹出 1，顺序 `[0,1]`。3 的入度减到 1。弹出 2，顺序 `[0,1,2]`。3 的入度减到 0：队列 `[3]`。
4. 弹出 3，顺序 `[0,1,2,3]`。4 个节点全部处理，所以没有环。

加上边 `(3, 0)`：现在节点 0 的入度为 1，没有入度为 0 的起点，顺序为空，`0 < 4` 说明存在环。

`[[1,1,0],[0,1,0],[0,0,1]]` 中的岛屿：从 (0,0) 开始，填充 (0,1)、(1,1)：第 1 个分量。格子 (2,2) 是未访问的陆地：第 2 个分量。答案 **2**，代价 $O(R \cdot C)$，因为每个格子只访问一次。

> [!TIP] 面试技巧
> - 说“无权图最短路径用 BFS，穷举探索和环检测用 DFS”，并给出 $O(V + E)$。
> - 编码前先澄清有向还是无向、是否有重复边、图是否连通。
> - 在入队时而不是出队时标记已访问，否则 BFS 可能爆炸；在网格上用显式栈避免递归深度问题。
> - 如果面试官加入权重，改用 Dijkstra（堆）；如果出现负边，用 Bellman-Ford。
