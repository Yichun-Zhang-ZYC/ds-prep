## 为什么重要
“生成所有子集 / 排列 / 合法组合”以及“摆放 N 皇后”是标准的回溯题。它们考察你能否把搜索表述为选择、探索、撤销，能否尽早剪枝，并分析指数级的代价。

## 概念
**递归**通过把问题化为更小的同类问题来求解：有一个终止的**基准情形**，以及朝它推进的**递归步骤**。代价 = （调用次数）$\times$（每次调用的工作量）；调用栈占用 $O(\text{depth})$ 空间。

**回溯** = 在部分解的**决策树**上做 DFS。模板：

```python
def backtrack(state, choices):
    if is_complete(state):
        record(state); return
    for c in choices:
        if not valid(state, c):   # prune early
            continue
        apply(state, c)           # choose
        backtrack(state, next_choices)  # explore
        undo(state, c)            # un-choose
```

**标准问题与规模**
| 问题 | 叶子 / 输出规模 | 时间 |
|---|---|---|
| $n$ 个元素的子集 | $2^n$ | $O(n \cdot 2^n)$ |
| $n$ 个元素的排列 | $n!$ | $O(n \cdot n!)$ |
| 组合总和（可重复使用） | 取决于目标值 | 指数级，经剪枝 |
| N 皇后 | $\le n!$，大量剪枝 | 节点数少得多 |

**避免重复**：先对输入排序，然后在同一递归层跳过与前一个相等的值（`i > start and a[i] == a[i-1]`）。允许元素重复使用时递归传 `i`；禁止时传 `i + 1`。

**剪枝**：当部分和超过目标时停止（先排序就能 `break`），N 皇后中用集合记录已占用的列和对角线（$O(1)$ 的攻击检查；对角线是 `r - c` 和 `r + c`）。

**常见陷阱**：记录的是当前路径的**副本**（`path[:]`），而不是列表本身；修改共享状态就必须撤销；递归深度有限（Python 约 1000）。如果相同的子问题重复出现，就用**记忆化**；这会把回溯变成动态规划。

## 示例讲解
`combination_sum([2, 3, 6, 7], 7)`（每个数可重复使用）。候选数已排序，`start` 是允许的最小下标，括号内是剩余目标：
1. 选 2（剩余 5），再选 2（剩余 3），再选 2：剩余 1，且所有候选数都更大，剪枝；回退。
2. 在剩余 3 时选 3：剩余 0，记录 `[2, 2, 3]`。选 6 或 7 会超出，所以剪枝（并 break，因为列表已排序）。
3. 回到剩余 5（路径 `[2]`），选 3：剩余 2；从下标 1 开始没有候选数 $\le 2$，死路。选 6、7：超出。
4. 路径 `[]`：选 3（剩余 4）：再选 3 剩余 1，死路；6 超出。选 6：剩余 1，死路。选 7：剩余 0，记录 `[7]`。

结果 `[[2, 2, 3], [7]]`。`[1, 2, 3]` 的子集遵循同样的树，产生 $2^3 = 8$ 个集合；$n = 4$ 的 N 皇后经过剪枝找到 **2** 个解，$n = 6$ 有 4 个，$n = 8$ 有 92 个。

> [!TIP] 面试技巧
> - 讲出模板：选择、探索、撤销；说明决策树的样子及其大小（$2^n$、$n!$）。
> - 尽早剪枝并说明如何剪；提到用排序来跳过重复和 `break` 循环。
> - 记录时一定要复制路径，并撤销每一次修改；大多数错误都出在这里。
> - 如果子问题重复出现（例如只数方案数而不列出），加上记忆化，并称之为动态规划。
