## 为什么重要
“满足……条件的最长/最短/最优连续子数组或子串”是最常见的面试题型之一。滑动窗口通过复用上一个窗口的计算结果，把 $O(n^2)$ 降到 $O(n)$。

## 概念
**窗口**是一段连续区间 `[l, r]`。你向右扩展 `r` 来纳入新元素，并收缩 `l` 来恢复条件，因此每个下标最多进入和离开窗口各一次：总共 $O(n)$。

两种类型：
- **固定大小 $k$**：加入 `a[r]`，移除 `a[r - k]`，更新滚动的和或计数。例子：任意 $k$ 个连续元素的最大和。
- **可变大小**：一直扩展到窗口无效（或有效），然后从左侧收缩。
  - *最长的有效窗口*：始终扩展，仅在无效时收缩，修复后记录长度。
  - *满足条件的最短窗口*：扩展到有效，然后在仍然有效时收缩，每次都记录。

模板（可变大小）：

```python
l = 0
for r in range(len(a)):
    add(a[r])
    while invalid():
        remove(a[l]); l += 1
    best = max(best, r - l + 1)
```

需要维护的状态：滚动的和、窗口内容的频次表或集合、不同字符的个数，或者用双端队列维护窗口最大/最小值。

**适用条件**：答案是连续子数组/子串，且有效性条件是*单调*的（收缩有效窗口仍然有效，或扩大无效窗口仍然无效）。含负数时，“和 $\ge$ target”的窗口不是单调的；应改用前缀和配合哈希表或双端队列。

复杂度：时间 $O(n)$；求和类空间 $O(1)$，字符映射为 $O(\min(n, |\Sigma|))$。

## 示例讲解
**无重复字符的最长子串**，输入 `"abcabcbb"`。维护映射 `last[ch]` = 最近出现的下标；当 `ch` 在窗口内重复时，把 `l` 移到 `last[ch] + 1`。

```text
r=0 'a'  l=0  window "a"    len 1  best 1
r=1 'b'  l=0  window "ab"   len 2  best 2
r=2 'c'  l=0  window "abc"  len 3  best 3
r=3 'a'  last[a]=0 >= l  -> l=1  window "bca"  len 3
r=4 'b'  last[b]=1 >= l  -> l=2  window "cab"  len 3
r=5 'c'  last[c]=2 >= l  -> l=3  window "abc"  len 3
r=6 'b'  last[b]=4 >= l  -> l=5  window "cb"   len 2
r=7 'b'  last[b]=6 >= l  -> l=7  window "b"    len 1
```

答案是 3，一次遍历，时间 $O(n)$。`last[ch] >= l` 这个检查很关键：位于 `l` 左侧的旧出现位置已不在窗口内，不能让 `l` 往回退。

> [!TIP] 面试技巧
> - 说明为什么是 $O(n)$：每个指针只向前移动，所以指针移动总数最多 $2n$，尽管代码里有循环套循环。
> - 明确不变式：每次迭代之后，窗口保证了什么？
> - 陷阱：负数会破坏求和类问题经典的收缩逻辑；改用前缀和加哈希表。
> - 陷阱：更新答案的时机不对（收缩之前还是之后）。对于最短窗口类问题，要在收缩循环内部记录。
