## 为什么重要
栈对应“最近的优先”（嵌套、撤销、DFS），队列对应“最早的优先”（BFS、调度）。括号匹配和单调栈（“下一个更大元素”）是最常被重复考察的两种面试模式。

## 概念
**栈（LIFO，后进先出）**：`push`、`pop`、`peek` 都是 $O(1)$。Python 中用 `list`（`append`/`pop`）。**队列（FIFO，先进先出）**：用 `collections.deque`（`append`/`popleft`，都是 $O(1)$）；`list.pop(0)` 是 $O(n)$，是经典的错误。

应用场景：
- **匹配 / 嵌套**：遇到左括号入栈，遇到右括号出栈并检查是否匹配。只有最后栈为空才合法。
- **表达式求值**、撤销、浏览器历史、迭代式 DFS（用显式栈代替递归）。
- **队列**：BFS（层序遍历、无权图最短路径）、任务调度、用 `deque` 实现的滑动窗口。
- **单调栈**：让栈保持递增（或递减）。当新元素破坏顺序时，弹出并结算被弹出的元素：*下一个更大/更小元素*、每日温度、柱状图中最大的矩形。每个元素入栈和出栈各一次，所以是 $O(n)$。
- **最小栈**：存储 `(value, current_min)` 对，使 `get_min` 为 $O(1)$。
- **用两个栈实现队列**：入队放入 `in`；当 `out` 为空时，把 `in` 中的所有元素倒入 `out`（顺序反转）。每个元素最多搬运一次，所以 `pop` 均摊 $O(1)$。

数据结构本身的空间是 $O(n)$。在单调栈中存**下标**而不是值，这样才能计算距离。

## 示例讲解
**每日温度**：对每一天，还要等几天才有更暖和的一天（没有则为 0）？输入 `[73, 74, 75, 71, 69, 72, 76, 73]`。维护一个存放温度递减的下标的栈；遇到更暖的一天，就结算栈中所有更冷的天。

```text
i=0 (73): stack []        -> push 0              stack [0]
i=1 (74): 74>73 pop 0     -> ans[0]=1-0=1        stack [1]
i=2 (75): 75>74 pop 1     -> ans[1]=1            stack [2]
i=3 (71): 71<75 no pop    -> push                stack [2,3]
i=4 (69): 69<71 no pop    -> push                stack [2,3,4]
i=5 (72): pop 4 (69)      -> ans[4]=1
          pop 3 (71)      -> ans[3]=2
          72<75 stop      -> push                stack [2,5]
i=6 (76): pop 5 (72)      -> ans[5]=1
          pop 2 (75)      -> ans[2]=4            stack [6]
i=7 (73): push                                   stack [6,7]
```

留在栈里的下标 6 和 7 始终没找到更暖的一天，所以保持为 0。结果是 `[1, 1, 4, 2, 1, 1, 0, 0]`，尽管 `for` 里面有 `while`，时间和空间仍是 $O(n)$。

> [!TIP] 面试技巧
> - 大声说出单调栈的不变式（“栈中的温度始终递减”），这表明你理解它为什么正确。
> - 陷阱：用 `list.pop(0)` 当队列；应使用 `deque` 并提到 $O(1)$ 的 `popleft`。
> - 陷阱：括号匹配时，遇到右括号忘记检查栈是否为空，以及最后忘记检查栈是否为空（`"(("`）。
> - 常见追问：用两个栈实现队列、最小栈，或能以 $O(1)$ 取最大值的栈。
