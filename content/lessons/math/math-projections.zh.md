## 为什么重要
最小二乘回归就是一次正交投影，PCA 重构和 Gram-Schmidt/QR 也是。把 OLS 看作“把 y 投影到 X 的列空间”，是解释残差、帽子矩阵以及残差为何与特征不相关的最清晰方式。

## 概念
**向量上的投影**：向 $a$ 投影，$\text{proj}_a(b) = \dfrac{a\cdot b}{a\cdot a}\,a = \dfrac{aa^\top}{a^\top a}\,b$。残差 $b - \text{proj}_a(b)$ 与 $a$ **正交**（勾股定理：$\|b\|^2 = \|\text{proj}\|^2 + \|\text{resid}\|^2$）。标量系数 $\frac{a\cdot b}{a\cdot a}$ 就是不含截距的一维最小二乘斜率。

**子空间上的投影**：设子空间由 $A$ 的列张成（列满秩），则 $p = A\hat x$，其中 $\hat x$ 满足**正规方程** $A^\top A\hat x = A^\top b$，于是
$$P = A(A^\top A)^{-1}A^\top, \qquad p = Pb.$$
- $P$ **对称**且**幂等**：$P^2 = P$（投影两次不再改变）。特征值为 0 或 1；$\text{rank}(P) = \text{tr}(P) = $ 子空间的维数。
- $I - P$ 投影到正交补；残差 $e = (I-P)b$ 满足 $A^\top e = 0$。
- 若有**标准正交基** $Q$（按列），则化简为 $P = QQ^\top$：$p = \sum_i (q_i\cdot b)\,q_i$，无需求逆。
- **Gram-Schmidt** 构造标准正交基：从每个新向量中减去它在之前各向量上的投影，再归一化。这就是 QR 分解，是求解最小二乘的稳定方法。

**最小二乘 = 投影**：$\hat y = X\hat\beta = Py$，帽子矩阵 $H = X(X^\top X)^{-1}X^\top$。残差满足 $X^\top e = 0$（与每个特征正交，包括截距列，所以残差之和为 0）。$\text{tr}(H) = $ 参数个数；对角元 $h_{ii}$ 是第 $i$ 个点的**杠杆值**。

**PCA 作为投影**：把中心化数据投影到前 $k$ 个特征向量 $V_k$ 上：$\hat X = XV_kV_k^\top$。在所有秩 $k$ 投影中它使平方重构误差最小（等价于保留的方差最大）。

注意：投影仅在标准内积下才是**正交**的；加权最小二乘使用不同的内积。若 $A$ 秩亏，$A^\top A$ 奇异（应使用伪逆）。

## 示例讲解
**一维**：把 $b = (2,3)$ 投影到 $a = (1,1)$。
- $\dfrac{a\cdot b}{a\cdot a} = \dfrac{5}{2}$，所以 $p = (2.5, 2.5)$，残差为 $(-0.5, 0.5)$。
- 正交性：$(-0.5)(1) + (0.5)(1) = 0$。勾股：$\|b\|^2 = 13 = \|p\|^2 + \|e\|^2 = 12.5 + 0.5$。

**过原点的回归**：点 $x = (1,2,3)$，$y = (1,3,2)$。把 $y$ 投影到 $x$：$\hat\beta = \dfrac{x\cdot y}{x\cdot x} = \dfrac{1+6+6}{1+4+9} = \dfrac{13}{14} \approx 0.929$。拟合值 $\hat y = \beta x \approx (0.93, 1.86, 2.79)$；残差 $\approx (0.07, 1.14, -0.79)$；验证 $x\cdot e = 0.07 + 2.29 - 2.36 \approx 0$。

**子空间**：把 $b = (1,2,3)$ 投影到由 $(1,0,0)$ 和 $(1,1,0)$ 张成的平面（xy 平面）。这组基不正交，所以先标准正交化：$q_1 = (1,0,0)$，$q_2 = (0,1,0)$。于是 $p = 1\cdot q_1 + 2\cdot q_2 = (1,2,0)$，残差 $(0,0,3)$ 与该平面正交。

> [!TIP] 面试技巧
> - 把 OLS 描述为 y 在 X 列空间上的正交投影：残差与特征正交，帽子矩阵对称且幂等。
> - 了解 trace(H) = 参数个数以及 h_ii 作为杠杆值，它们会出现在回归诊断中。
> - 提到用 QR（Gram-Schmidt）稳定地求解最小二乘，而不是直接用正规方程。
