## 为什么重要
交叉熵是逻辑回归、softmax 分类器和语言模型背后的损失函数，而熵是决策树划分的基础。面试官会让你定义两者、解释为什么最小化交叉熵等价于极大似然，并解读以 bit 或 nat 为单位的数值。

## 概念
分布 $p$ 的**熵**是平均意外程度，也是编码来自该分布的样本所需的最小平均比特数：
$$H(p) = -\sum_x p(x) \log p(x)$$
用 $\log_2$ 得到 bit，用 $\ln$ 得到 nat；约定 $0 \log 0 = 0$。均匀分布时熵最大（$K$ 个结果时为 $\log K$），确定性分布时为 0。

**交叉熵**是样本来自 $p$、但使用为 $q$ 设计的编码时的平均码长：
$$H(p, q) = -\sum_x p(x) \log q(x) = H(p) + D_{KL}(p \,\|\, q) \ge H(p)$$

**在机器学习中**：当标签 $p$ 是 one-hot（真实类别为 $y$）时，$H(p, q) = -\log q_y$：即真实类别的**负对数似然**。所以最小化交叉熵损失就是极大似然。对于二分类标签，这就是对数损失：$-[y \log \hat p + (1-y)\log(1-\hat p)]$。

**相关概念**：条件熵 $H(Y \mid X)$，以及决策树使用的信息增益 $= H(\text{parent}) - \sum_k \frac{n_k}{n} H(\text{child}_k)$。**困惑度** $= 2^{H}$（用 nat 时为 $e^{H}$）是等可能选择的有效个数；语言模型会报告它。

## 示例讲解
设 $p = (0.5, 0.25, 0.25)$。

$H(p) = -(0.5 \log_2 0.5 + 2 \cdot 0.25 \log_2 0.25) = 0.5 + 1 = 1.5$ bit。

用均匀模型 $q = (1/3, 1/3, 1/3)$ 编码：$H(p, q) = \log_2 3 \approx 1.585$ bit。每个符号多出的 $0.085$ bit 就是 $D_{KL}(p \| q)$，即使用错误模型的代价。

分类：如果真实类别被预测的概率为 0.7，损失为 $-\ln 0.7 \approx 0.357$ nat；概率为 0.1 时为 $-\ln 0.1 \approx 2.303$。该损失会严厉惩罚自信的错误答案，且当 $q_y \to 0$ 时趋于无穷。

> [!TIP] 面试技巧
> - 定义 $H(p, q) = H(p) + D_{KL}(p\|q)$，并说明交叉熵损失就是真实类别的负对数似然。
> - 记住参照点：对 $K$ 个类别的均匀预测损失为 $\ln K$ nat（检验未训练分类器的快速方法）。
> - 陷阱：对 0 取对数。要对概率做截断，或基于 logits 使用 log-softmax 以保证数值稳定。
