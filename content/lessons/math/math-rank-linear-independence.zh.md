title: 秩与线性无关
---

## 为什么重要
秩告诉你一个矩阵包含多少独立信息。它解释了为什么特征共线时回归会失败、为什么低秩分解能压缩数据，以及为什么方程组会有零个、一个或无穷多个解。这是常见的概念类面试题。

## 概念
**线性无关**：向量 $v_1,\dots,v_k$ 线性无关，当且仅当 $c_1v_1 + \dots + c_kv_k = 0$ 只在 $c_1=\dots=c_k=0$ 时成立。否则某个向量是其他向量的组合（冗余）。
- 在 $\mathbb{R}^n$ 中超过 $n$ 个向量必然线性相关。
- 空间的**基**是一组张成该空间的线性无关向量；其个数就是**维数**。

**秩**：$\text{rank}(A)$ = 独立列数 = 独立行数（列秩 = 行秩）= 非零奇异值的个数 = 列空间的维数。恒有 $\text{rank}(A) \le \min(m, n)$。
- **满秩**：秩 $= \min(m,n)$。方阵可逆当且仅当满秩。
- **秩-零度定理**：$\text{rank}(A) + \text{nullity}(A) = n$（列数），其中零空间为 $\{x : Ax = 0\}$。
- $\text{rank}(AB) \le \min(\text{rank}A, \text{rank}B)$；$\text{rank}(X^\top X) = \text{rank}(X)$。
- 秩为 1 的矩阵是外积 $uv^\top$。

**如何计算**：高斯消元化为行阶梯形，秩 = 主元个数。数值上使用 SVD 并统计大于容差的奇异值，因为浮点噪声使“恰好为零”不可靠。

**线性方程组** $Ax = b$（$A$ 为 $m\times n$）：有解当且仅当 $b$ 在列空间中（$\text{rank}[A\,|\,b] = \text{rank}A$）。解唯一当且仅当秩 $= n$；否则有无穷多解（沿零空间平移）。

**与机器学习的联系**：
- **多重共线性**：若某个特征是其他特征的线性组合（例如为每个类别都建哑变量再加截距），$X^\top X$ 奇异，OLS 系数不唯一。可以删除一列、使用岭回归或伪逆。
- 当 $n < d$（样本数少于特征数）时，$\text{rank}(X) \le n < d$，所以 $X^\top X$ 必然奇异。
- 低秩结构：矩阵分解和 LoRA 用秩 $r \ll \min(m,n)$ 的瘦矩阵乘积来近似大矩阵。

## 示例讲解
考虑 $M = \begin{pmatrix}1&2&3\\2&4&6\\1&0&1\end{pmatrix}$ 的各行。
- 第 2 行 $= 2\times$ 第 1 行，所以各行线性相关。消元：$R_2 - 2R_1 = (0,0,0)$，$R_3 - R_1 = (0,-2,-2)$。
- 主元：第 1 列（来自 $R_1$）和第 2 列（来自 $R_3 - R_1$）。共 **2 个主元**，所以 $\text{rank}(M) = 2$，$\det M = 0$。
- 零度 $= 3 - 2 = 1$；一个零空间向量是 $(1, 1, -1)$：$1+2-3 = 0$，$2+4-6 = 0$，$1+0-1 = 0$。
- 特征工程视角：一张含 $x$、$2x$、$x+1$（以及常数列）的表，秩是 2 而不是 4；$X^\top X$ 不可逆，OLS 有无穷多个等价解。
