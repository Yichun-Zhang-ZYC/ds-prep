## 为什么重要
特征向量是线性映射只对其做拉伸的方向。它们是 PCA、谱聚类、PageRank、动力系统稳定性以及梯度下降分析的基础。常见问题包括：它们的含义、如何为小矩阵计算，以及与 PCA 的联系。

## 概念
**定义**：$Av = \lambda v$，其中 $v \ne 0$。向量 $v$ 方向不变；$\lambda$ 是拉伸系数（为负则反向）。特征向量只在相差一个比例下确定。

**求法**：解特征方程 $\det(A - \lambda I) = 0$ 得到 $\lambda$，再解 $(A - \lambda I)v = 0$ 得到 $v$。$n\times n$ 矩阵有 $n$ 个特征值（计重数，可能是复数）。

**关键恒等式**：
- $\text{tr}(A) = \sum \lambda_i$，$\det(A) = \prod \lambda_i$。因此 $\det A = 0 \iff$ 存在为 0 的特征值（奇异）。
- $A^k$ 的特征值为 $\lambda^k$；$A^{-1}$ 的为 $1/\lambda$；$A + cI$ 的为 $\lambda + c$（特征向量相同）。
- **特征分解**：若 $A$ 有 $n$ 个线性无关的特征向量，则 $A = Q\Lambda Q^{-1}$。
- **对称矩阵**（协方差、$X^\top X$、Hessian）：特征值为**实数**，特征向量可取**标准正交**，所以 $A = Q\Lambda Q^\top$（谱定理）。并非所有矩阵都可对角化（例如剪切变换）。

**幂迭代**求主特征对：重复 $v \leftarrow Av / \|Av\|$。它收敛到最大 $|\lambda|$ 对应的特征向量，每步的收敛率为 $|\lambda_2/\lambda_1|$（要求特征值有间隔，且初始向量在 $v_1$ 方向上有分量）。特征值由**瑞利商** $\lambda = v^\top A v / v^\top v$ 给出。变体：逆迭代（求最小值）、Lanczos/Arnoldi（大型稀疏矩阵），用于 PageRank 和谱方法。

**与机器学习的联系**：
- **PCA**：协方差矩阵的特征向量是主方向；特征值是沿该方向的方差。解释方差比 $= \lambda_i / \sum\lambda$。
- **马尔可夫链 / PageRank**：平稳分布是转移矩阵中 $\lambda = 1$ 对应的特征向量。
- **优化**：对二次函数，梯度下降稳定当且仅当 $\eta < 2/\lambda_{\max}$，速度取决于条件数 $\lambda_{\max}/\lambda_{\min}$。
- **谱聚类**使用图拉普拉斯矩阵的特征向量。

## 示例讲解
设 $A = \begin{pmatrix}2&1\\1&2\end{pmatrix}$（对称）。
- 特征多项式：$\det\begin{pmatrix}2-\lambda&1\\1&2-\lambda\end{pmatrix} = (2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = (\lambda-3)(\lambda-1)$。所以 $\lambda = 3, 1$。
- 验证：迹 $= 4 = 3+1$；行列式 $= 3 = 3\cdot1$。
- $\lambda = 3$：$(A-3I)v = 0 \Rightarrow v = (1,1)/\sqrt2$。$\lambda=1$：$v = (1,-1)/\sqrt2$。两者正交，正如谱定理所保证。
- 从 $(1, 0)$ 开始的幂迭代：$A(1,0) = (2,1)$，然后 $A(2,1) = (5,4)$，然后 $A(5,4) = (14,13)$。方向趋向 $(1,1)$，次大与最大特征值之比为 $1/3$，所以每步误差约缩小 3 倍。$(14,13)$ 处的瑞利商：$v^\top Av/v^\top v = (14\cdot41 + 13\cdot40)/(14^2+13^2) = 1094/365 \approx 2.997$。

> [!TIP] 面试技巧
> - 把特征向量定义为只被 A 拉伸的方向；提到迹 = 特征值之和、行列式 = 特征值之积，作为快速检验。
> - 对于对称矩阵，说明特征值为实数、特征向量正交（谱定理），这是 PCA 性质良好的原因。
> - 了解幂迭代及其失效情形（没有谱间隔，或初始向量与主特征向量正交）。
