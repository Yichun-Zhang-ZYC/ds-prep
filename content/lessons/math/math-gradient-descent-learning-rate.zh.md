---

## 为什么重要
梯度下降是几乎所有机器学习训练的引擎，学习率是最重要的超参数。面试官会问训练为何发散、稳定步长是多少、特征缩放为何有帮助，以及学习率调度、动量和 Adam 带来什么变化。

## 概念
**更新规则**：$\theta_{t+1} = \theta_t - \eta\,\nabla L(\theta_t)$，其中 $\eta$ 为学习率（步长）。每一步沿最陡下降方向移动。

**二次函数分析**（极小值附近一切行为的模型）：对 $L = \frac12\theta^\top H\theta$，曲率为 $\lambda$ 的每个特征方向按 $\theta \leftarrow (1 - \eta\lambda)\theta$ 演化。因此：
- 收敛当且仅当对所有 $\lambda$ 有 $|1 - \eta\lambda| < 1$，即 $\eta < 2/\lambda_{\max}$。
- 最佳固定学习率为 $\eta = 2/(\lambda_{\max} + \lambda_{\min})$；最慢方向的收缩率约为 $\frac{\kappa - 1}{\kappa + 1}$，其中**条件数** $\kappa = \lambda_{\max}/\lambda_{\min}$。
- 所需步数约与 $\kappa \log(1/\epsilon)$ 成正比。病态问题会在陡峭方向来回震荡，而在平缓方向缓慢爬行。

**学习率的几种状态**：太小则进展缓慢；太大则震荡或发散（损失上升或出现 NaN）；略低于 $2/\lambda_{\max}$ 则很快但不稳定。实用做法：选择能稳定训练的最大学习率。

**缓解病态的方法**：标准化特征（使 $\kappa$ 更接近 1）、动量、自适应优化器（Adam、RMSProp）、预条件、二阶方法。

**学习率调度**：阶梯衰减、余弦衰减、预热（对 Transformer 和 Adam 很重要，因为早期梯度统计量噪声大）以及平台期降低。衰减 $\eta$ 让 SGD 能够稳定在某个极小值。

**收敛保证**：对 $L$-光滑的凸函数 $f$，$\eta = 1/L$ 给出 $f(\theta_T) - f^* = O(1/T)$；强凸则给出线性（几何）收敛。

**诊断**：在对数坐标下画损失曲线；做学习率扫描（LR range test）；情况异常时与梯度检查对比。

## 示例讲解
**一维二次函数** $f(x) = 5x^2$（$\lambda = 10$，稳定性上限为 $\eta < 0.2$）。从 $x_0 = 1$ 出发，每步把 $x$ 乘以 $1 - 10\eta$：
- $\eta = 0.05$：因子 $0.5$，$x_{10} \approx 0.001$，平滑收敛。
- $\eta = 0.1$：因子 $0$，一步收敛（理想学习率 $1/\lambda$）。
- $\eta = 0.15$：因子 $-0.5$，震荡收敛。
- $\eta = 0.25$：因子 $-1.5$，$|x_{10}| = 1.5^{10} \approx 57.7$，发散。

**病态问题** $f = \tfrac12(x^2 + 100y^2)$ 的 $\kappa = 100$，上限为 $\eta < 2/100 = 0.02$。取 $\eta = 0.019$，从 $(1, 1)$ 出发：$y$ 方向因子为 $|1 - 1.9| = 0.9$（震荡但在缩小），$x$ 方向因子为 $0.981$。要使 $\|(x, y)\| < 10^{-3}$ 约需 $361$ 步，全都耗在平缓的 $x$ 方向上。如果重新缩放 $y$ 使 $\kappa = 1$，用 $\eta = 1$ 一步就能解决。
