## 为什么重要
量化是服务大模型最便宜的方式：内存更小、带宽占用更少，解码往往更快。面试官想听到基本数学、PTQ 与 QAT 的区别，以及为什么异常值让 LLM 难以量化。

## 概念
**量化**用更少的比特存储权重（有时还包括激活值或 KV cache）。内存为 $\text{参数量} \times \text{位数}/8$ 字节。

**$b$ 位的仿射 / 对称方案**：
- 对称 absmax：$s = \max|w| / (2^{b-1} - 1)$，$q = \text{round}(w / s)$，$\hat w = s\,q$。
- 非对称再加一个**零点** $z$：$q = \text{round}(w/s) + z$，适合分布偏斜的范围，例如 ReLU 之后的激活值。
- **粒度**：按张量（粗）、按通道，或**按组**（例如 128 个权重共用一个缩放因子）。组越细误差越低，但缩放因子的存储更多。

**时机**：
- **PTQ**（训练后量化）：用少量校准集量化已训练好的模型，无需重新训练。LLM 的标准做法。
- **QAT**（量化感知训练）：在前向传播中模拟取整（梯度用直通估计器）。极低位数下效果更好，但需要训练算力。

**针对 LLM 的方法**：
- **LLM.int8()**：激活值有少数几个极大的异常通道；这些通道保持 fp16，其余用 int8。
- **SmoothQuant**：通过按通道重新缩放，把激活异常值迁移到权重上，使 W8A8 可行。
- **GPTQ**：逐层 PTQ，利用二阶信息更新剩余权重来补偿每次取整误差。
- **AWQ**：根据激活幅度找出约 1% 的关键权重，量化前先缩放以保护它们。

**仅权重 vs 权重+激活**：W4A16 节省内存，并加速受内存带宽限制的解码；W8A8 还能使用 int8 张量核心，对计算受限的预填充和大批量有帮助。量化 KV cache 可扩展上下文或批大小。用困惑度和下游任务评估；8 位几乎无损，4 位有小幅下降，低于 4 位需要格外小心。

## 示例讲解
权重 $[0.50, -1.28, 0.013, 2.54]$ 用 8 位：$s = 2.54/127 = 0.02$，编码 $[25, -64, 1, 127]$，反量化为 $[0.50, -1.28, 0.02, 2.54]$。小权重 0.013 变成了 0.02（误差 0.007），其余几乎精确。

现在加入一个异常值 12.7：$s = 0.1$，于是 $0.50 \to 5$，$-1.28 \to -13$（反量化为 $-1.3$），而 $0.013 \to 0$ 彻底丢失。一个异常值浪费了所有权重的取值范围，这就是按组缩放有帮助的原因。

7B 参数的内存：fp16 为 14 GB，int8 为 7 GB，int4 为 3.5 GB。

> [!TIP] 面试技巧
> - 写出 absmax 公式，再解释零点以及按通道或按组的缩放因子。
> - 把异常值解释为核心难点，并说出一种解决方法（LLM.int8、SmoothQuant、GPTQ 或 AWQ）。
