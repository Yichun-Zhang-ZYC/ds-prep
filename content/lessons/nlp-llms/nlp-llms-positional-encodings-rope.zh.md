## 为什么重要
自注意力对输入顺序是置换等变的，模型只能通过你选择的位置方案感知词序。这一选择也决定了模型向更长上下文外推的能力。面试官会让你推导 RoPE 的相对位置性质，并与 ALiBi 和可学习位置嵌入比较（基础机制见“自注意力与多头注意力”）。

## 概念
**绝对位置方案**在第 1 层之前把位置向量加到 token 嵌入上。
- **可学习**：可训练的表 $E_{pos}[0..L-1]$（BERT、GPT-2）。简单，但超过 $L$ 的位置不存在。
- **正弦**（原始 Transformer）：$PE_{pos,2i} = \sin(pos/10000^{2i/d})$，$PE_{pos,2i+1} = \cos(pos/10000^{2i/d})$。固定的几何级数波长，从 $2\pi$ 到 $10000 \cdot 2\pi$；$PE_{pos+k}$ 是 $PE_{pos}$ 的线性函数，理论上有助于相对位置推理。实践中在训练长度之外的外推能力较差。

**相对位置方案**把偏移量 $m-n$ 直接注入注意力分数。
- **RoPE**（旋转位置编码；Llama、Qwen、Mistral、GPT-NeoX）：把 query 和 key 的每个二维分量对按与其位置成正比的角度旋转，$\theta_i = b^{-2i/d}$，默认基数 $b = 10000$。设旋转矩阵为 $R_m$，则 $\langle R_m q, R_n k\rangle = q^\top R_{n-m} k$，分数只依赖**相对距离**，而 $q$、$k$ 的范数不变。它在每一层作用于 $Q$ 和 $K$（不作用于 $V$），不增加参数；下标小的分量对旋转快（局部细节），下标大的旋转慢（长程）。
- **ALiBi**（BLOOM、MPT）：完全没有位置向量；给 logits 加上与注意力头相关的线性惩罚 $-m_h\,(i-j)$。斜率为几何级数，$m_h = 2^{-8h/H}$，$h = 1..H$。长度外推很好，但有强烈的近因偏置，长程检索能力不如带缩放的 RoPE。
- **T5 相对偏置**：对每个（分桶后的）距离和每个头学习一个标量，加到 logits 上。
- **NoPE**：因果解码器仅靠掩码就能推断位置，但大规模使用很少见。

**RoPE 为何胜出**：具备相对位置特性、无额外参数、兼容 KV cache（key 在自己的位置上旋转一次即可），并且可以通过缩放频率来扩展上下文（见“长上下文技术”）。

**常见陷阱**：模型从未在超过 $L$ 的位置上训练过，推理时会遇到分布外的旋转角度；头维度 $d$ 必须为偶数；旋转基数是超参数，训练和部署时必须一致。

## 示例讲解
使用 $d = 2$（一个分量对）的 RoPE，每个位置旋转 $\theta = 1$ 弧度。取 $q = k = (1, 0)$，旋转后 $R_m q = (\cos m, \sin m)$。

query 在位置 3，key 在位置 1：$\langle R_3 q, R_1 k\rangle = \cos 3 \cos 1 + \sin 3 \sin 1 = \cos(3-1) = \cos 2 \approx -0.416$。

两者都平移 10（位置 13 和 11）：$\cos 13 \cos 11 + \sin 13 \sin 11 = \cos 2$，分数相同。只有偏移量 2 起作用。

正弦编码，$pos = 1$、$d = 4$：第 0 对的除数为 $10000^0 = 1$，得到 $(\sin 1, \cos 1) = (0.841, 0.540)$；第 1 对的除数为 $10000^{0.5} = 100$，得到 $(\sin 0.01, \cos 0.01) = (0.010, 1.000)$。前面的维度振荡很快，后面的几乎不动，就像时钟的各位数字。

> [!TIP] 面试技巧
> - 写出 RoPE 恒等式 $\langle R_m q, R_n k\rangle = q^\top R_{n-m}k$，并说明它每层只作用于 Q 和 K。
> - 对比：可学习（硬上限）、正弦（外推差）、ALiBi（外推好但有近因偏置）、RoPE（相对位置，可通过频率缩放扩展）。
> - 指出在部署时改变 RoPE 基数或训练长度会悄悄破坏模型。
