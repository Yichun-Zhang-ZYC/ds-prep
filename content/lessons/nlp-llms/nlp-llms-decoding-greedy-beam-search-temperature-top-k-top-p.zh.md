## 为什么重要
同一个模型，取决于解码方式，听起来可以很确定，也可以很有创意。面试官希望你精确解释 temperature、top-k 和 top-p，能为任务选择设置，并知道束搜索何时有用。

## 概念
模型在词表上输出 logits $z$；**解码策略**决定下一个 token。

- **贪心**：始终取 $\arg\max$。快速且确定，但可能重复，并且会错过那些前几个 token 单独看不是最可能的序列。
- **束搜索**：保留得分最高的 $B$ 个部分序列（得分 = 对数概率之和，通常做**长度归一化**）。适合翻译、摘要和语音识别这类有唯一正确答案的任务；对开放式文本会产生平淡、重复的输出。
- **采样**：从分布中抽取，可选地先重塑分布：
  - **温度**：$p_i = \dfrac{e^{z_i / T}}{\sum_j e^{z_j / T}}$。$T < 1$ 使分布更尖锐（$T \to 0$ 时趋向贪心），$T > 1$ 使其更平坦（更随机），$T = 1$ 是模型原始分布。
  - **Top-k**：只保留最可能的 $k$ 个 token，重新归一化。
  - **Top-p（核采样）**：保留累积概率 $\ge p$ 的**最小**头部 token 集合，重新归一化。候选集合会**自适应**：模型有把握时只有 1 个 token，不确定时有很多个，不像固定的 $k$。
  - 另外还有：min-p、重复 / 频率惩罚。

典型顺序：温度 → top-k / top-p 过滤 → 重新归一化 → 采样。代码、信息抽取和问答用低 $T$（0-0.3）；头脑风暴和创意写作用较高的 $T$（$0.7$-$1.0$）。即使 $T = 0$ 在 GPU 上也不能保证逐比特复现（浮点归约的非确定性、批处理）。

## 示例讲解
Logits 为 $[2, 1, 0]$。$T = 1$ 时：$e^2, e^1, e^0 = 7.389, 2.718, 1$，和为 $11.107$，所以 $p = [0.665, 0.245, 0.090]$。$T = 0.5$ 时 logits 变为 $[4, 2, 0]$：$[54.60, 7.39, 1]/62.99 = [0.867, 0.117, 0.016]$，更尖锐。

概率 $[0.5, 0.3, 0.15, 0.05]$：
- **Top-k = 2**：保留 $0.5, 0.3$，除以 $0.8$ 重新归一化：$[0.625, 0.375]$。
- **Top-p = 0.9**：累积概率 $0.5, 0.8, 0.95$。第三个 token 使累积超过 0.9，所以保留三个 token；除以 $0.95$ 重新归一化：$[0.526, 0.316, 0.158]$。

> [!TIP] 面试技巧
> - 给出温度公式及其极限（$T \to 0$ 为贪心，$T \to \infty$ 为均匀分布）。
> - 解释 top-p 会适应模型的置信度而 top-k 不会；两者经常组合使用。
> - 按任务选择：确定性任务用束搜索 / 低 $T$，开放式生成用采样。
