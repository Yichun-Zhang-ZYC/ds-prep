## 为什么重要
预训练目标决定了模型之后能做什么：生成、理解还是嵌入。面试官会让你比较因果语言模型、掩码语言模型和去噪目标，并论证为什么大多数 LLM 使用下一个 token 预测。

## 概念
所有目标都是**自监督**的：标签来自文本本身，因此数据可以扩展到数万亿 token。

| 目标 | 破坏输入 | 预测 | 上下文 | 典型模型 |
|---|---|---|---|---|
| **因果语言模型（CLM）** | 无 | 下一个 token | 仅左侧 | GPT、Llama |
| **掩码语言模型（MLM）** | 掩盖约 15% 的 token | 被掩盖的 token | 两侧 | BERT、RoBERTa |
| **Span corruption** | 丢弃片段并加入哨兵 | 被丢弃的片段 | 编码器：两侧；解码器：因果 | T5、UL2 |
| **替换 token 检测** | 用小型生成器替换 token | 逐 token 判断原始或被替换 | 两侧 | ELECTRA |
| **对比学习** | 数据增强或配对文本 | 在负例中匹配正例 | 整段文本 | SimCSE、CLIP、嵌入模型 |

- **CLM 损失**：$\mathcal{L} = -\frac{1}{n-1}\sum_{t} \log p(x_{t+1} \mid x_{\le t})$。每个位置都提供训练信号。
- **MLM 损失**：同样的交叉熵，但**仅对被掩盖位置**取平均，所以每个序列只提供约 15% 的信号。ELECTRA 通过对所有位置做分类找回了效率。
- **生成**：CLM 与推理完全一致（没有训练/测试差距）。MLM 模型无法流畅生成，但在分类和检索上，每个参数提供更好的双向特征。
- **目标混合**：UL2 结合短片段、长片段和 prefix-LM 去噪；**中间填充**（FIM）训练代码模型插入文本。
- **下一句/句子顺序**目标作用不大，已被舍弃。
- **为什么 CLM 在大规模下胜出**：简单、与生成无不匹配、所有 token 信号均匀、扩展规律清晰，并且会涌现出上下文能力。
- 预训练损失是词表上的交叉熵；其指数就是困惑度。对齐阶段（指令微调、RLHF）在其后，使用不同的目标。

## 示例讲解
模型预测一个有两个 `[MASK]` 位置的句子，给真实 token 的概率分别为 0.2 和 0.5。MLM 损失 $= -(\ln 0.2 + \ln 0.5)/2 = (1.609 + 0.693)/2 = 1.151$ nat。

对于 100 个 token 的序列：CLM 有 99 项损失；MLM 约有 15 项。要达到 CLM 的信号量，BERT 式训练需要约 6.6 倍的数据遍数，这是因果语言模型样本效率更高的原因之一。

词表大小为 $V = 4$ 的均匀模型损失为 $\ln 4 = 1.386$，这是检查任何实现的便捷方法（困惑度 4）。

```reveal

  "prompt": "面试题：为什么不在仅解码器 LLM 上，用 MLM 式的双向掩码只预测一小部分 token 来获得更好的表示？",
  "answer": "可以（那就是 BERT），但需要权衡：（1）只有约 15% 的位置提供信号，样本效率较低；（2）`[MASK]` token 造成训练与推理的不匹配；（3）没有额外机制时模型无法从左到右生成，而且提示/上下文学习在 CLM 上效果要好得多；（4）CLM 清晰的扩展规律使它成为超大算力下的稳妥选择。对于分类和检索，双向模型按参数计仍然更好，所以编码器仍在这些场景使用；prefix-LM 或 UL2 混合目标则试图兼得两者。"
}
```

> [!TIP] 面试技巧
> - 能写出 CLM 损失，并说明 MLM 的不同之处（仅被掩盖位置、双向上下文）。
> - 把目标与下游用途联系起来：CLM 用于生成，MLM 用于编码器和嵌入，span corruption 用于 seq2seq。
> - 使用健全性检查：未训练模型的损失应约为 $\ln V$。
