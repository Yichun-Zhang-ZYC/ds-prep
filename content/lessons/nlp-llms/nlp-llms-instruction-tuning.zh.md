## 为什么重要
预训练的 LLM 只会续写文本，不会遵循指令。指令微调（监督微调，SFT）是把基座模型变成助手的第一步，面试官会问它改变了什么、损失如何计算以及需要什么数据。

## 概念
**监督微调**在（指令，回复）对上训练基座模型，使用与预训练相同的下一个 token 交叉熵，但是：
- 文本被包装进**对话模板**（标记 system / user / assistant 轮次的特殊 token），让模型知道在哪里回答、何时停止（EOS）。
- 损失**只在回复 token 上计算**。提示词 token 被屏蔽（PyTorch/HF 中标签为 `-100`），这样模型学的是*回答*，而不是模仿用户的提问。
- 典型配方：1-3 个 epoch，小学习率（$10^{-5}$ 到 $2 \times 10^{-5}$），把较短的序列**打包**以填满上下文窗口。

**数据**：
- **质量胜于数量**：LIMA 表明约 1,000 条精心挑选的样本就能得到一个很强的对话模型。
- 来源：人工撰写的示范、改写成指令形式的任务集合（FLAN），以及由更强模型生成的**合成**数据（Self-Instruct、Alpaca；注意教师模型的许可协议）。
- 任务和格式的多样性比大量近似重复的数据更重要。

**作用**：主要教会模型*格式、风格和遵循指令*，并能泛化到未见过的任务（零样本）。它很少增加新的*知识*。在模型本来不知道的事实上微调，可能教会它自信地瞎猜，**增加幻觉**。

**局限**：SFT 只是模仿示范；它无法判断两个可接受的答案哪个*更好*。这正是偏好微调（RLHF / DPO，下一课）补充的部分。

## 示例讲解
提示词 token 为 `[11, 12, 13]`，回复 token 为 `[21, 22]`，EOS 的 id 为 `2`。
- `input_ids = [11, 12, 13, 21, 22, 2]`
- `labels    = [-100, -100, -100, 21, 22, 2]`

三个未被屏蔽位置的逐 token 损失为 $1.2, 0.6, 0.3$。SFT 损失是它们的平均值，$2.1 / 3 = 0.7$。如果对全部六个位置取平均（错误地包含提示词），会稀释信号，并让模型去预测用户文本。

> [!TIP] 面试技巧
> - 要说“只在 assistant token 上计算损失”和“带 EOS 的对话模板”；这是大家常忘的细节。
> - 把 SFT 描述为教会行为而不是知识；要增加知识用 RAG 或继续预训练。
> - 提到数据质量和多样性胜过规模（LIMA），以及合成数据的风险（错误、许可、模式坍塌）。
