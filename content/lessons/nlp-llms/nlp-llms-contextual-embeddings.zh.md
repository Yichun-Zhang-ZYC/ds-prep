## 为什么重要
静态 embedding 给 `bank` 只有一个向量，既表示河岸又表示银行。上下文 embedding 让“预训练再微调”成为 NLP 的默认做法。面试官会问：一个词的向量如何依赖于它所在的句子、该用哪一层，以及 ELMo 与 BERT 有何不同。

## 概念
**上下文 embedding** 是深层序列模型在某个 token 位置的隐状态，因此它是整个句子的函数：$h_i = f(w_1, \dots, w_n)_i$。同一个词型在 `river bank` 和 `bank loan` 中得到不同的向量，从而解决了多义词问题。

**演进**：
- **ELMo（2018）**：两层**双向 LSTM** 语言模型（一个前向 LM、一个后向 LM，拼接），用预测下一个/上一个词来预训练。特征被冻结，并**按任务混合**：$\text{ELMo}_k = \gamma \sum_{j=0}^{L} s_j h_{k,j}$，其中层权重 $s$ 经 softmax 归一化，$\gamma$ 为标量。
- **GPT**：从左到右的 **transformer 解码器**；每个 token 只能看到之前的 token。端到端微调。
- **BERT**：用掩码语言建模训练的**双向 transformer 编码器**，所以每个 token 的向量同时利用左右上下文。

**用哪一层？** 低层捕捉表层和句法信息，高层捕捉更偏语义、更偏任务的信息（探测研究）。对于冻结特征，加权混合或最后 4 层平均往往优于只用最后一层。对于微调，则训练整个网络加一个小的输出头。

**两种用法**：
- **基于特征**：冻结模型，把 embedding 输入单独的分类器（ELMo 风格）。
- **微调**：在下游任务上更新所有权重（BERT/GPT 风格）；通常更强。

**实践要点**：向量是按子词 token 给出的，所以要把片段池化成词向量（取第一个片段或取平均）。同一个词的上下文向量是**各向异性**的：它们挤在一个狭窄的锥体里，所以原始余弦相似度都偏高。推理时上下文同样重要：成本随序列长度增长，且每个输入都要运行编码器，不像静态查表那样便宜。

## 示例讲解
对一个 token 做三层的 ELMo 式混合：$h_0 = [1, 0]$（embedding 层），$h_1 = [0, 1]$，$h_2 = [2, 2]$，标量 logits $s = [0, 0, \ln 2]$，$\gamma = 1$。

softmax 权重：$e^0 = 1, 1, 2$，总和为 $4$，即 $[0.25, 0.25, 0.5]$。混合向量：$0.25[1,0] + 0.25[0,1] + 0.5[2,2] = [1.25, 1.25]$。训练时，任务损失会学习 $s$ 和 $\gamma$，因此每个任务都可以强调自己需要的那一层。

> [!TIP] 面试技巧
> - 一句话：静态 = 每个词型一个向量；上下文 = 每个 token 出现一个向量，由整个句子计算得到。
> - 对比 ELMo（两个单向 LSTM 的浅层拼接，基于特征）和 BERT（深度双向 transformer，微调）。
> - 陷阱：未经微调就把 `[CLS]` 向量或原始最后一层当作句向量；效果往往很差（见句向量）。
