## 为什么重要
情感分析、命名实体识别（NER）和文本分类是工业界最基本的 NLP 任务。面试重点在于你如何定义任务（序列标注还是分类）、如何根据手头数据选择模型，以及如何正确评估。

## 概念
**文本分类**把文档映射到标签：垃圾邮件、主题、意图、情感。**情感分析**是分类（正面/负面/中性）或回归（星级评分），有时是方面级的（“电池好，屏幕差”）。

模型阶梯，按应当尝试的顺序：
1. **TF-IDF + 逻辑回归 / 线性 SVM / 朴素贝叶斯**：快速、强基线、权重可解释。
2. **微调预训练编码器**（BERT 系列）：有几百到几千条标注时准确率最高。
3. **零样本/少样本 LLM 提示**：不需要标注，适合原型和长尾标签；每次调用更贵更慢。

难点：否定（`not good`）、讽刺、领域偏移（影评 vs 客服工单）以及标签噪声。词袋对否定处理不好，除非加入 bigram。

**NER** 是**序列标注**：每个 token 都有一个标签。**BIO** 方案用 `B-X`（类型 X 实体的开头）、`I-X`（实体内部）和 `O`（实体外部）标记，使相邻实体保持分开。模型：基于手工特征的 CRF（经典）、BiLSTM-CRF，或 BERT token 分类器。子词 token 继承其第一个片段的标签。

**评估**：
- 分类：只有类别平衡时才用准确率；否则用精确率、召回率、F1（每个类别都重要时用宏平均，常见类别占主导时用微平均）以及混淆矩阵。
- NER：**实体级**（span 级）精确率/召回率/F1，要求类型和边界都完全匹配，而不是 token 准确率；`O` token 占多数，会抬高 token 准确率。
- 始终先划分数据再拟合向量化器或调参；对于不平衡数据，考虑类别权重和阈值调整。

## 示例讲解
句子 `Barack Obama visited Paris`。真实标签：`B-PER I-PER O B-LOC`。预测：`B-PER O O B-LOC`。

token 准确率是 $3/4 = 75\%$，看起来还不错。在实体级别：真实 span 为 $\{\text{PER}[0,2), \text{LOC}[3,4)\}$，预测为 $\{\text{PER}[0,1), \text{LOC}[3,4)\}$。只有 LOC 完全匹配：$TP = 1$，精确率 $= 1/2$，召回率 $= 1/2$，$F_1 = 0.5$。部分匹配的 PER span 既算假阳性也算假阴性。

> [!TIP] 面试技巧
> - 先用 TF-IDF + 逻辑回归做基线再考虑 transformer；说明多大的准确率提升才值得付出成本。
> - 陷阱：对 NER 报告 token 级准确率，或对不平衡类别报告准确率。应使用实体级 F1、PR 曲线和分类别指标。
> - 先谈数据问题：标注质量、标注规范、领域偏移，以及对误分类样本做错误分析。
