## 为什么重要
“模拟一下”是解概率题的万能后备方案，而模拟也是 DS 团队检查统计功效、验证统计方法（A/A 测试）以及在没有闭式解时估计数值的方法。面试官经常让你用模拟来验证答案。

## 概念
**蒙特卡洛**：通过对大量随机抽样取平均来估计某个量。根据大数定律，估计会收敛；其标准误按 $1/\sqrt{N}$ 缩小（抽样次数增加 4 倍 → 误差减半）。

步骤：
1. 写一个模拟**单次试验**并返回结果的函数。
2. 运行 N 次（或用 NumPy 一次性向量化所有试验）。
3. 取平均，并报告标准误：对于比例 $\hat p$，SE $= \sqrt{\hat p(1-\hat p)/N}$。

```python
rng = np.random.default_rng(42)          # seeded generator for reproducibility
rolls = rng.integers(1, 7, size=(100_000, 2))
p_sum_7 = (rolls.sum(axis=1) == 7).mean()   # ≈ 1/6
```

常用模式：
- **向量化试验**：生成一个（试验数 × 步数）的数组，而不是写嵌套循环。
- **功效分析**：在假定的效应下模拟实验，运行检验，统计 p < 0.05 的频率。
- **A/A 测试**：没有效应时，假阳性率应 ≈ α；否则说明方法有问题。
- **自助法（Bootstrap）**：对观测数据有放回地重抽样，得到抽样分布。
- **随机游走 / 排队 / 库存**：逐步模拟过程。

陷阱：忘记设置随机种子；稀有事件的试验次数太少（p 很小时需要多得多的抽样）；无意中在不同条件间复用相同的随机数；用 Python 循环跑数百万次试验（应向量化或减小 N）。

## 示例讲解
23 人的生日问题：模拟 20,000 组，检查是否有任意两人同一天生日。

```python
b = rng.integers(0, 365, size=(20_000, 23))
s = np.sort(b, axis=1)
p = (np.diff(s, axis=1) == 0).any(axis=1).mean()   # ≈ 0.507
```
精确答案是 0.507；SE ≈ $\sqrt{0.25/20000} \approx 0.0035$。

> - 始终设置随机种子，并报告标准误（∝ 1/√N）。
> - 提到用模拟做功效分析，以及用 A/A 测试验证实验流水线。
