## 为什么重要
数据科学家的评价标准之一是沟通得多清楚。“你会怎样可视化 X？”这类问题考察你能否让图表与问题匹配，并避免误导性的设计。

## 概念
按**问题**选择图表，而不仅仅看数据类型：

| 问题 | 图表 |
|---|---|
| 随时间的趋势 | 折线图（离散时期很少时用柱状图） |
| 比较类别 | 排序后的水平柱状图；点图 |
| 单个变量的分布 | 直方图、KDE、箱线图/小提琴图、ECDF |
| 比较各组的分布 | 箱线图/小提琴图、叠加的 ECDF、分面直方图 |
| 两个数值变量之间的关系 | 散点图（+ 趋势线），n 很大时用 hexbin |
| 部分与整体 | 堆叠柱状图、100% 柱状图；饼图只用于 2–3 个部分 |
| 多个变量之间的相关性 | 热力图 |
| 漏斗 / 转化步骤 | 漏斗图，或带每步转化率的水平柱状图 |
| 带不确定性的估计 | 点 + 误差线（置信区间）、森林图 |
| 地理 | 分级统计地图（要按人口归一化！） |

避免误导性的图表：
- **柱状图**截断 y 轴会夸大差异（柱子编码的是从零开始的长度）。
- 双 y 轴可以暗示任何你想要的相关性。
- 3D 效果、颜色太多、类别不排序、切片很多的饼图。
- 在真正重要的是比率时画计数（大地区总是有更多）。
- 挑选对自己有利的时间窗口。

设计：每张图只传达一个信息，标题说明洞察（“v5.2 之后移动端转化下降了 12%”），标注单位，尽量直接给线条加标签而不用图例，突出重点、其余置灰。

## 示例讲解
问题：“结账页改版是否改变了 12 个市场的转化率？”较弱的做法：24 个转化率的分组柱状图。更好的做法：每个市场的**差值**（处理组 − 对照组）及 95% 置信区间的点图，排好序，并在零处画一条竖线。读者一眼就能看到效应大小和确定性。

> [!TIP] 面试技巧
> - 从问题出发（“趋势？比较？分布？”），说出能回答它的图表。
> - 为估计值展示不确定性（置信区间），并把计数归一化为比率。
> - 指出误导性的做法：截断的柱状图坐标轴、双坐标轴、切片很多的饼图。
