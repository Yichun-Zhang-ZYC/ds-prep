## 为什么重要
“应该控制哪些变量？”直觉上的回答（“全都控制”）是错的。因果图（DAG）给出了有原则的答案，也有助于在面试中解释混杂变量、中介变量和对撞变量。

## 概念
**DAG** 把变量画成节点，把因果效应画成箭头。三种基本结构：

| 结构 | 形状 | 要控制它吗？ |
|---|---|---|
| **混杂变量** | X ← Z → Y | **要**：Z 制造了一条虚假的路径 |
| **中介变量** | X → M → Y | 如果想要**总**效应就不要（控制它会阻断一部分效应） |
| **对撞变量** | X → C ← Y | **不要**：以 C 为条件会制造出虚假的关联 |

目标是**阻断所有后门路径**（从 X 到 Y、以指向 X 的箭头开始的路径），同时不阻断因果路径，也不打开对撞路径。

对撞偏差很隐蔽，也很常见：“在被录用的候选人中，编程能力和沟通能力呈负相关”（录用要求至少具备其中一项，所以按录用筛选就把两者联系了起来）。

## 示例讲解
问题：使用移动 App（X）会增加购买（Y）吗？

- **参与度 / 兴趣**同时影响 App 使用和购买 → 混杂变量 → 要控制（例如实验前时段的活跃度）。
- **会话次数**由 App 使用导致，又会推动购买 → 中介变量 → 如果想要总效应就不要控制。
- **“收到了满意度调查”**（发给使用过 App 或购买过的人）→ 对撞变量 → 不要只看调查的回答者。

> [!TIP] 面试技巧
> - 选择控制变量之前先画一张 DAG；这能体现结构化的因果思维。
> - 控制混杂变量；（求总效应时）不要控制中介变量或对撞变量。
> - 用 Berkson 悖论或录用的例子快速解释对撞偏差。
