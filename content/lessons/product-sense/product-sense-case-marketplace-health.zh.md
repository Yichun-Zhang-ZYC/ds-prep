## 为什么重要
Uber、Airbnb、DoorDash、Etsy 和 eBay 都依赖双边市场，“你如何衡量我们市场的健康度？”是标准的产品感问题。只看 GMV 会掩盖某一侧已经“挨饿”。

## 概念
**核心思想：流动性（liquidity）。**当带着明确意图而来的买家能快速找到合适的匹配，加入的供给方能获得足够需求而留下来，市场就是健康的。需要同时衡量两侧以及两侧之间的匹配。

**需求侧**：搜索到下单转化率、**成交率（fill rate）**（最终完成交易的请求占比）、**成交时间**（或 ETA、配送时长）、复购率、买家 NPS。

**供给侧**：**利用率**（至少有一笔交易的房源、司机或卖家占比，或可用时段被预订的占比）、每小时收入、新供给激活率（N 天内首单）、供给留存。

**匹配质量**：取消率（分买家和供给方）、评分、纠纷或退款率、价格离散度。

**市场整体健康**：
- **抽成率（take rate）** = 收入 / GMV。提高抽成可能挤压供给。
- **集中度**：前 10% 供给方贡献的 GMV 占比。集中度高说明脆弱，也说明长尾难做。
- **脱离平台（leakage / disintermediation）**：首次匹配后用户转到线下交易。
- **流动性是本地的**：应按城市、品类和时段定义。全局平均会掩盖“死”市场。

**诊断失衡**：
- 成交率低且供给利用率高：**供给受限**。招募供给或增加激励。
- 成交率高且供给利用率低：**需求受限**。拉动需求，停止招募供给。
- 两者都低：**错配**（位置、价格、质量或搜索排序有问题）。

**实验注意事项**：买家共享供给，所以单侧 A/B 测试违反 SUTVA（存在干扰）。应使用聚类、地理或轮换（switchback）实验，并把估计当作上限。

## 示例讲解
某房屋租赁市场想知道为什么一个城市增长停滞。上周数据（示意）：

| 指标 | 数值 |
|---|---|
| 预订请求 | 5,000 |
| 完成预订 | 3,000 |
| 确认时间中位数 | 42 分钟 |
| 活跃房源 | 4,000 |
| 至少有 1 单的房源 | 1,200 |
| GMV / 抽成率 | \$150,000 / 15% |
| 前 10% 房东（400 人）的预订量 | 2,100 |

- 成交率 = 3,000 / 5,000 = **60%**：偏低。供给利用率 = 1,200 / 4,000 = **30%**：也偏低。
- 集中度：2,100 / 3,000 = **70%** 的预订来自 10% 的房东。
- 平台收入 = 15% × \$150,000 = \$22,500。

**诊断**：在库存充足的情况下两侧都不满意，所以这是**错配**，而不是房东不够。多数房源从未被订到，需求侧也看不到足够好的选择。假设：房源位置不对或定价高于同类，搜索排序没有展示最好的房东，确认太慢（42 分钟）导致房客流失。

**行动**：优化排序和筛选，增加即时预订，辅导或下架“僵尸”房源，并停止花钱招募房东。**护栏指标**：取消率、评分、房东流失。**衡量**：用城市级轮换或地理实验，因为房客和房东共享同一批库存。

> [!TIP] 面试技巧
> - 以流动性开场：同时衡量两侧以及两侧之间的匹配，并按本地（城市 x 品类 x 时段）而不是全局 GMV 来看。
> - 用成交率和供给利用率诊断：供给受限、需求受限或错配，各自对应不同的解法。
> - 提到实验中的干扰、脱离平台、集中度，以及抽成率与供给健康之间的权衡。
