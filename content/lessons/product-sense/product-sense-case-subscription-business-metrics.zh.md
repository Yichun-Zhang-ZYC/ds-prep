## 为什么重要
Netflix、Spotify、Duolingo 以及所有 SaaS 公司都靠订阅运转。“你会跟踪订阅产品的哪些指标？”考察你能否搭出收入瀑布、区分增长与留存，并判断单位经济模型。基础定义可参见“收入、ARPU、LTV 与 CAC”和“留存与流失”两课。

## 概念
**MRR 瀑布**解释月度经常性收入（MRR）的每一处变化（年付套餐折算为月）：

$$MRR_{end} = MRR_{start} + \text{New} + \text{Expansion} - \text{Contraction} - \text{Churned}$$

**收入口径的留存**（针对期初已存在的同一批客户）：
- **总收入留存（GRR）** = (期初 − 降级 − 流失) / 期初。上限为 100%，衡量“漏水”程度。
- **净收入留存（NRR）** = (期初 + 扩展 − 降级 − 流失) / 期初。高于 100% 表示存量客户自己就在增长。顶尖的 B2B SaaS 常高于 110%。
- **客户（logo）流失**按客户数计，**收入流失**按金额计。大客户行为不同时二者会背离。

**增长效率**：
- **SaaS 快速比率** = (新增 + 扩展) / (降级 + 流失)。经验法则：高于 4 很好，低于 1 表示在萎缩。
- **LTV**（月流失率 $c$ 恒定）：$LTV = \dfrac{ARPA \times GM}{c}$，预期生命周期为 $1/c$ 个月。
- **CAC 回收期（月）** = CAC / (ARPA × GM)。**LTV:CAC** 约 3 以上是常见目标。

**消费者订阅漏斗**：访客 → 开始试用 → 试用转付费 → 第 1、3 个月留存 → 续费率（年付套餐只有一个很大的续费悬崖）。区分**主动流失**（取消）和**被动流失**（扣款失败，通常占流失的 20-40%，可通过催款重试和银行卡更新器挽回）。

**常见陷阱**：
- 简单 LTV 公式假设流失率恒定，但流失在早期最高（队列曲线随后趋平），应使用队列来估计。
- 折扣和免费试用会抬高注册量但降低质量；应按获客来源和优惠比较队列。
- 靠降价做大收入规模，却损害了 ARPA 和流失率。
- 暂停、降级和重新激活流程会模糊“流失”的含义：要精确定义每种状态。

## 示例讲解
一款 B2B 工具有 2,000 个客户，ARPA 为 \$50（示意数据），本月报告如下：

| 组成 | MRR |
|---|---|
| 期初 | \$100,000 |
| 新增 | + \$12,000 |
| 扩展 | + \$5,000 |
| 降级 | − \$2,000 |
| 流失（60 个客户） | − \$3,000 |
| **期末** | **\$112,000** |

- **GRR** = (100 − 2 − 3) / 100 = **95%**。**NRR** = (100 + 5 − 2 − 3) / 100 = **100%**。存量保持稳定；全部净增长（+12%）来自新客户。
- **快速比率** = (12 + 5) / (2 + 3) = **3.4**：健康，但依赖获客。
- 客户流失 = 60 / 2,000 = 每月 3%。毛利率 80% 时：$LTV = 50 \times 0.8 / 0.03 \approx$ \$1,333。
- 若 CAC 为 \$400：LTV:CAC ≈ **3.3**，回收期 = 400 / (50 × 0.8) = **10 个月**。

**解读**：单位经济模型尚可，但 NRR 仅 100% 意味着增长依赖投入。优先事项：提高扩展收入（席位或用量升级）、降低每月 3% 的流失（从 3% 降到 2% 会使 LTV 提高 50%），并查看流失中有多少是被动流失。护栏：不要用拉低 ARPA 的折扣来换扩展。

> [!TIP] 面试技巧
> - 从 MRR 瀑布开始：新增、扩展、降级和流失说明增长从哪里来、从哪里漏。
> - 区分 GRR 与 NRR、客户流失与收入流失、主动流失与被动流失。
> - 说明 LTV 的假设（流失率恒定、毛利率），并优先使用队列曲线；把指标与决策挂钩，例如先拉动哪个杠杆。
