## 为什么重要
备件、慢销 SKU 和长尾零售商品大多数日子销量为零，偶尔有一次较大的销量。常规工具会失效：ARIMA 和 ETS 假设连续取值，MAPE 会除以零，而“每天 0.4 件”这样的均值预测是一个永远不会出现的数字。面试官借此考察你能否把预测与库存决策联系起来。

## 概念
**定义**：存在大量零需求的时期，非零需求的数量也不固定。用两个数字描述序列：
- **ADI**（平均需求间隔）$=\dfrac{\text{总期数}}{\text{有需求的期数}}$。
- **非零**需求量的 $\text{CV}^2$ $=(\sigma/\mu)^2$。

**Syntetos-Boylan 分类**使用 ADI $=1.32$ 和 $\text{CV}^2 = 0.49$ 为分界：平稳（低，低）、**波动（erratic）**（ADI 低，CV$^2$ 高）、**间歇（intermittent）**（ADI 高，CV$^2$ 低）、**块状（lumpy）**（高，高）。

**Croston 方法**分别平滑两个分量，且只在发生需求时更新：
- 量 $z_t = \alpha d_t + (1-\alpha) z_{t-1}$，间隔 $p_t = \alpha q_t + (1-\alpha) p_{t-1}$，其中 $q_t$ 是距上一次需求的期数。
- 预测 $\hat d = z / p$（每期期望需求），是一条**水平**直线。
- Croston 存在向上偏差；**SBA**（Syntetos-Boylan 近似）乘以 $1 - \alpha/2$ 来修正。**TSB**（Teunter-Syntetos-Babai）则每期都更新需求*概率*，因此需求停止后预测会衰减，能处理产品淘汰（Croston 会永远保留最后的速率）。

**替代方案**：简单指数平滑或移动平均在基准测试中往往与 Croston 不相上下；**聚合**到周或月，或聚合到更高的层级（参见《层次预测与调和》）；**ADIDA/IMAPA** 时间聚合；在大量商品上使用带计数似然（泊松、**负二项**、Tweedie）的全局 GBM 或深度模型；**hurdle** 模型（P(有需求) x 需求量）。

**选对目标**：补货需要的是**提前期需求**的分布，而不是每期均值。计算提前期 $L$（加盘点周期）内需求的某个服务水平分位数：若每期速率为 $\lambda$ 的泊松过程，提前期需求服从 Poisson($\lambda L$)；间歇性数据通常过度离散，因此要用负二项或自助法。订货上限（order-up-to）就是该分位数。

**评估**：**MAPE 和 sMAPE 无效**（有零）；当朴素误差为零或极小时 MASE 不稳定；应使用 **RMSSE**、缩放的 MSE、偏差（平均误差），并针对决策使用服务水平分位数上的**分位数损失**，以及在仿真中的实际满足率/缺货和库存成本（参见《概率预测与预测区间》）。注意 MAE 的最小化者是**中位数**，而稀疏序列的中位数为 0：全部预测为 0 的模型在 MAE 上可能看起来最好。

## 示例讲解
示意性例子：8 期需求为 `[0, 0, 5, 0, 0, 0, 4, 0]`。ADI $= 8/2 = 4$；非零量 $[5, 4]$ 均值 4.5、方差 0.25，所以 $\text{CV}^2 = 0.25/20.25 = 0.012$：**间歇型**。

取 $\alpha = 0.1$ 的 Croston：在第一次需求（第 3 期）初始化：$z = 5$，$p = 3$。第 7 期（量 4，间隔 $7-3 = 4$）：$z = 0.1\cdot4 + 0.9\cdot5 = 4.9$，$p = 0.1\cdot4 + 0.9\cdot3 = 3.1$。预测为 $4.9/3.1 = 1.58$ 件/期；SBA 得到 $1.58 \times 0.95 = 1.50$。没有任何一期会恰好卖出 1.58 件，所以应该看它所对应的库存。

提前期 4 期：提前期需求均值约为 $6.3$。对 Poisson($6.32$)，累积概率在 9 处为 0.892，10 处为 0.943，11 处为 0.972，因此 95% 的服务水平需要约 **11 件**的订货上限，几乎是均值的两倍。（真实的间歇性需求是过度离散的，因此负二项会要求更多。）

> [!TIP] 面试技巧
> - 用 ADI 和 CV$^2$ 分类，再把 Croston 解释为分别平滑量和间隔，并说明 SBA/TSB 的改进。
> - 明确指出 MAPE 在零值上失效，应使用 RMSSE、偏差和分位数损失评估，最好通过库存结果来衡量。
> - 把预测与决策联系起来：提前期需求分布和服务水平分位数，而不是均值。
> - 提到聚合、计数数据似然和全局模型等实际替代方案。
