## 为什么重要

在架构之后，选择并计算正确的指标是推荐系统面试中最常见的问题。你必须能手算 Recall@k、MAP 和 NDCG，并解释为什么离线的提升并不总能转化为线上的提升。

## 概念

**离线指标**用留出的交互来评估排序列表（使用**按时间划分**，而不是随机划分，以避免泄漏）。对排序列表 $r_1, \ldots, r_k$ 和相关集合 $\mathcal{R}$：
- **Precision@k** $= \frac{|\text{top }k\text{ 中的命中数}|}{k}$；**Recall@k** $= \frac{|\text{top }k\text{ 中的命中数}|}{|\mathcal{R}|}$（召回阶段指标）。
- **MRR** $= \frac1{\text{第一个命中的排名}}$。
- **AP@k** $= \frac{1}{\min(|\mathcal{R}|, k)} \sum_{i \le k} P@i \cdot \text{rel}_i$；**MAP** 是对用户的平均。
- **NDCG@k** $= \text{DCG@k}/\text{IDCG@k}$，其中 $\text{DCG@k} = \sum_{i=1}^{k} \frac{2^{\text{rel}_i}-1}{\log_2(i+1)}$。它支持**分级**相关性并对靠后位置打折；IDCG 是理想排序的 DCG。

**超越准确率**：覆盖率、多样性、新颖性、意外性、推荐校准以及公平性。**在线指标**才是真正的目标：CTR、观看时长、转化、留存、每次会话收入，通过 **A/B 测试**衡量，并配合护栏指标（延迟、投诉、创作者健康度）。Interleaving 可以更灵敏地比较两个排序器。

**为什么离线和在线不一致**：日志数据来自旧策略（**选择与曝光偏差**），因此未展示的物品没有标签；位置偏差抬高了靠前位置；离线准确率忽略了反馈回路、新奇效应和用户疲劳；而且优化点击可能损害长期留存。使用带有日志倾向得分的反事实估计器（IPS、doubly robust）可获得更好的离线估计，并始终用在线实验来验证。

## 示例讲解

一个排序列表的分级相关性为 $[3, 2, 0, 1]$，$k = 3$。$\text{DCG@3} = 7/1 + 3/\log_2 3 + 0 = 7 + 1.893 = 8.893$。理想顺序为 $[3, 2, 1]$：$\text{IDCG@3} = 7 + 1.893 + 1/2 = 9.393$，所以 $\text{NDCG@3} = 0.947$。二值例子：排序物品 $[1,2,3,4]$，相关集合 $\{1,3,9\}$，$k=3$。命中在第 1 和第 3 位，所以 $\text{Recall@3} = 2/3$，$\text{AP@3} = (1/1 + 2/3)/\min(3,3) = 0.556$。

> [!TIP] 面试技巧
> - 按阶段选择指标：召回用 Recall@k，排序用 NDCG/MAP，产品目标用在线 CTR/留存。
> - 提到按时间划分、采样负例评估的陷阱，以及日志数据中的位置偏差。
> - 说明离线指标用于加快迭代，必须用带护栏的 A/B 测试来确认。
