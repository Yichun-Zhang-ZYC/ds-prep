## 为什么重要

生产环境的推荐系统几乎都是混合式的：对热用户/热物品用协同信号，对冷用户/冷物品用内容信号。面试官想听到各种组合策略及其权衡。

## 概念

**混合**方法把协同过滤（CF）与内容/辅助信息结合，使二者互补：CF 缺少特征且有冷启动问题，基于内容的方法则过度专一。

常见设计：
- **加权**：把两个分数归一化到同一尺度（min-max 或 z-score）后 $s = \alpha\, s_{\text{cf}} + (1-\alpha)\, s_{\text{cb}}$。
- **切换**：用户或物品的交互少于 $n$ 次时用基于内容的方法，否则用 CF。
- **特征增强 / stacking**：把 CF 的输出（embedding、分数）与内容特征一起作为特征输入排序模型（如 GBDT）。
- **级联 / 混合展示**：一个模型生成候选，另一个排序；或并排展示两者的列表。
- **模型层面**：单个模型同时包含 ID embedding **和**特征塔（two-tower、Wide & Deep、LightFM），ID 未见过时由内容特征提供 embedding。

**基于置信度的混合**：让 CF 的权重随数据量增长，例如 $\alpha = \frac{n}{n + k_0}$，其中 $n$ 是用户的交互次数。新用户依赖内容或热门度；重度用户依赖 CF。

**陷阱**：不同模型的原始分数尺度不同，必须归一化或使用排名（reciprocal rank fusion）；$\alpha$ 要在留出数据上按人群分段调参；混合模型增加了线上服务复杂度，也更难调试。

## 示例讲解

某用户有 $n = 5$ 次交互，$k_0 = 5$，则 $\alpha = 0.5$。三个物品的 CF 分数 $[1,2,3]$ 经 min-max 归一化为 $[0, 0.5, 1]$；内容分数 $[3,0,6]$ 归一化为 $[0.5, 0, 1]$。混合结果：$[0.25, 0.25, 1.0]$。新用户（$n=0$）的 $\alpha=0$，混合结果完全由内容决定：$[0.5, 0, 1]$。

> [!TIP] 面试技巧
> - 列出各种模式（加权、切换、stacking、级联、带特征塔的单模型），并针对场景选一种。
> - 一定要提到分数归一化，或基于排名的融合（如 reciprocal rank fusion）。
> - 把混合方法与冷启动联系起来：在积累足够交互之前，由内容特征支撑新用户和新物品。
