---

## 为什么重要
三门问题是最著名的反直觉概率谜题。面试官用它（及其变体）来看你是否从信息产生的过程出发推理，而不是凭直觉。

## 概念
三扇门：一扇后面是汽车，两扇后面是山羊。你选一扇门。主持人**知道汽车在哪里**，他从另外两扇门中打开一扇有山羊的门，然后问你要不要换。

- 坚持不换只有在第一次就选中汽车时才赢：**1/3**。
- 只要第一次选的是山羊，换门就会赢：**2/3**。

关键在于主持人的规则。他从不打开有汽车的门，所以他的选择带有信息。如果他是随机开门、恰好开出了山羊，换门的胜率就只有 1/2。

## 示例讲解
用贝叶斯的视角。你选了 1 号门，主持人打开了 3 号门。设 $C_i$ = 汽车在第 $i$ 扇门后。

$$
P(\text{opens } 3 \mid C_1) = \tfrac12,\quad P(\text{opens } 3 \mid C_2) = 1,\quad P(\text{opens } 3 \mid C_3) = 0
$$

$$
P(C_2 \mid \text{opens } 3) = \frac{1 \cdot \frac13}{\frac12 \cdot \frac13 + 1 \cdot \frac13} = \frac{2}{3}
$$
