title: 离散型与连续型随机变量
---

## 为什么重要
选择模型要从结果的类型开始：计数（每天的订单数）是离散的，测量值（停留时长）是连续的。搞混会导致选错分布、用错检验。

## 概念
**随机变量**把每个结果映射成一个数字。

| | 离散型 | 连续型 |
|---|---|---|
| 取值 | 可数（0, 1, 2, …） | 区间内的任意值 |
| 描述方式 | PMF：$P(X = x)$ | PDF $f(x)$：概率是面积 |
| 单个取值的 $P(X = x)$ | 可以 > 0 | 总是 0 |
| 例子 | 点击数、次品数、骰子点数 | 延迟、身高、人均收入（近似） |

对连续变量，$P(a \le X \le b) = \int_a^b f(x)\,dx$，所以 $P(X \le b)$ 和 $P(X < b)$ 相等。

有些真实数据是**混合型**的：大部分用户的人均收入恰好为 0（一个点质量），而购买者的收入是连续的。

## 示例讲解
页面加载时间 $X$ 在 1 到 3 秒之间均匀分布：在 $[1, 3]$ 上 $f(x) = 1/2$。

$$
P(X \le 1.5) = \int_1^{1.5} \tfrac{1}{2}\,dx = 0.25 \qquad P(X = 2) = 0
$$

密度值 $1/2$ 不是概率；区间很短时，密度甚至可以大于 1。

> [!TIP] 面试技巧
> - 提出分布或检验之前，先说出结果的类型。
> - 被问到为什么 P(X = x) = 0 时，回答“概率是密度曲线下的面积”。
> - 主动指出零膨胀、混合型的结果（收入、使用时长），它们很常见，面试官很欣赏这种细节。
