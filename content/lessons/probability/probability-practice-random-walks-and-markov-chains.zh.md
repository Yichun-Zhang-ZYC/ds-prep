## 为什么重要

随机游走与马尔可夫链是赌徒破产题、“到达 X 的期望时间”谜题以及 PageRank 式推理的基础。本套题训练三类反复出现的计算：吸收概率、期望击中时间和平稳分布。定义见随机游走与马尔可夫链相关课程。

## 概念

**赌徒破产**（以概率 $p$ 走 $+1$，以 $q$ 走 $-1$，在 0 和 $N$ 处吸收）：从 $i$ 出发，若 $p = q$ 则 $P(\text{先到 } N) = i/N$，否则为 $\frac{1 - r^i}{1 - r^N}$，其中 $r = q/p$。公平时期望持续时间为 $i(N-i)$。公平游走从 0 到达 $\pm a$ 平均需要 $a^2$ 步。

**首步分析**是核心工具：令 $h_i$ 为从状态 $i$ 出发的某个量，写出 $h_i = c + \sum_j P_{ij}h_j$，并在吸收态处给出边界值，然后解线性方程组。对于吸收链，设瞬时块为 $Q$、转入吸收态的块为 $R$：$N = (I-Q)^{-1}$，期望步数 $= N\mathbf 1$，吸收概率 $= NR$。

**平稳分布**：$\pi P = \pi$，$\sum\pi_i = 1$。对不可约、非周期的有限链，它唯一且 $P^n \to \mathbf 1\pi$。捷径：细致平衡 $\pi_i P_{ij} = \pi_j P_{ji}$（可逆链；图上的随机游走满足 $\pi_i \propto \deg i$）；期望回访时间 $= 1/\pi_i$（Kac）。

**路径计数**：对触及某水平线的游走用反射原理；选票定理：A 得 $a$ 票，B 得 $b < a$ 票，A 全程领先的概率为 $(a-b)/(a+b)$。对称的一维或二维游走以概率 1 回到原点，但期望时间为无穷；三维游走是瞬时的。

**检查清单**：定义状态使未来只依赖于现在（若不满足，就把记忆加进状态）；检查吸收态；在声称收敛之前检查不可约性和周期性。

## 示例讲解

从 $\{0, \dots, 10\}$ 的 5 出发，以 0.6 的概率向上、0.4 的概率向下。求 $P(\text{先到 } 10)$ 和期望步数。

这里 $r = q/p = 2/3$。$r^5 = 0.1317$，$r^{10} = 0.01734$。所以 $P = (1 - 0.1317)/(1 - 0.01734) = 0.8683/0.9827 = 0.8836$。

持续时间：$q - p = -0.2$，所以 $D = \frac{5}{-0.2} - \frac{10}{-0.2}\cdot 0.8836 = -25 + 50\cdot 0.8836 = 19.18$ 步，比公平游走的 25 步短，因为漂移让游走更快到达某一端。合理性检查：每步漂移为 $+0.2$，两端各距 5，所以大致是 $5/0.2 = 25$ 向上，再因早期在 0 处被吸收而缩短。

> [!TIP] 面试技巧
> - 说出“首步分析”，并在做任何代数之前写出带边界条件的方程。
> - 掌握闭式结果（$i/N$、$i(N-i)$、$a^2$、$\pi \propto$ 度数），并能推导其中一个；提到有偏游走使用 $r = q/p$。
> - 易错点：状态空间设错（忘记记忆，例如模式匹配需要最近几次的结果），以及把平稳分布用于周期或可约的链。
