## 为什么重要
Dropout 是神经网络最常用的正则化方法，面试官喜欢追问细节：为什么要乘以 $1/(1-p)$、推理时怎么处理、与 L2 有何不同。

## 概念
训练时，以概率 $p$ 独立地把每个激活置零，并把**保留下来的激活乘以 $1/(1-p)$**（*inverted dropout*）：
$$y_i = \frac{m_i}{1-p}\,x_i, \qquad m_i \sim \text{Bernoulli}(1-p)$$
这样 $\mathbb{E}[y_i] = x_i$，所以**推理时 dropout 就是恒等变换**，不需要额外缩放。

- **为什么有效**：单元无法依赖特定的搭档（*共适应*），特征必须更鲁棒。它近似于对指数量级的“瘦身”子网络取平均（隐式集成）。
- **反向传播**：梯度乘以同样的掩码和缩放：$\partial L/\partial x = (m/(1-p)) \odot \partial L/\partial y$。被丢弃的单元梯度为零。
- **常用比率**：大型全连接层 $p = 0.5$；Transformer 中（嵌入、注意力权重、FFN 输出）为 $0.1$ 到 $0.3$；卷积层很小或为零。
- **变体**：空间 dropout（整通道丢弃，因为相邻像素相关）、DropConnect（丢弃权重）、随机深度 / DropPath（丢弃整个残差块）、**MC dropout**（测试时保持 dropout 开启，多次前向取平均以估计不确定性）。
- **注意事项**：它会减慢收敛，需要训练更久。与 BatchNorm 同时使用会使训练和评估之间的方差发生偏移，所以要谨慎搭配。大型 LLM 预训练通常不使用 dropout，因为数据量巨大且只训练一个 epoch。
- 与 L2 相比，dropout 是一种自适应的、依赖数据的噪声正则化；两者经常一起使用。

## 示例讲解
激活 $x = (2, 4, 6, 8)$，$p = 0.5$，均匀随机数 $u = (0.1, 0.7, 0.4, 0.9)$。当 $u \ge p$ 时保留：掩码 $= (0, 1, 0, 1)$。缩放系数 $= 1/(1-0.5) = 2$。

训练输出：$(0, 8, 0, 16)$。这一次抽样的和为 24，而原值之和为 20；但在多次抽样中每个元素的期望都是 $x_i$（例如第 2 个元素：$0.5 \cdot 8 = 4$）。推理时输出就是 $(2, 4, 6, 8)$。

上游梯度为 $(1, 1, 1, 1)$ 时的反向传播：$(0, 2, 0, 2)$。

> [!TIP] 面试技巧
> - 解释 inverted dropout：在训练时缩放，推理时无需改动。
> - 提到 model.eval() 会关闭 dropout，以及 MC dropout 是用于估计不确定性的例外。
> - 要知道它是正则化手段：过拟合时使用；$p$ 太大会导致欠拟合。
