## 为什么重要
注意力最初是为了解决 seq2seq 的瓶颈而提出的，后来成为现代模型的核心。面试官会问它的来源、加性与点积打分有何不同，以及什么是交叉注意力。（Transformer 的自注意力与多头细节见 NLP 课程。）

## 概念
**动机**：编码器-解码器 RNN 把整个源句子压缩成一个固定向量，对长输入来说这是瓶颈。**注意力**（Bahdanau 等，2014）让解码器在每个输出步回看*所有*编码器状态，并挑选相关的部分。

**通用流程**：设**查询** $q$（解码器状态）、**键** $k_j$ 和**值** $v_j$（编码器状态）：
1. 对每个位置**打分**：$e_j = \text{score}(q, k_j)$。
2. **归一化**：$\alpha = \text{softmax}(e)$，得到和为 1 的权重（软对齐）。
3. **聚合**：上下文 $c = \sum_j \alpha_j v_j$，即送入解码器的加权平均。

**打分函数**：
- **加性**（Bahdanau）：$e_j = v^\top \tanh(W_q q + W_k k_j)$，一个小型 MLP。查询与键维度不同时也适用。
- **乘性 / 点积**（Luong）：$e_j = q^\top k_j$；“general”形式：$q^\top W k_j$。更快，适合矩阵乘法。
- **缩放点积**（Transformer）：$q^\top k_j/\sqrt{d_k}$，因为点积随维度增大，会使 softmax 饱和。

**性质与用途**：
- 一切都是可微的（**软注意力**），可以端到端训练。*硬*注意力只采样一个位置，需要类似 REINFORCE 的训练方式。
- **掩码**（把被屏蔽位置的分数设为 $-\infty$）用于处理填充；在解码器中还用于屏蔽未来的 token。
- **交叉注意力**：查询来自一个序列，键/值来自另一个序列（解码器到编码器、图像描述中的文本到图像区域）。**自注意力**：三者都来自同一个序列。
- 对 $n$ 个查询和 $m$ 个键，代价为 $O(nm)$；注意力权重有一定可解释性，但不能证明模型的推理过程。
- 它把位置之间的梯度路径缩短到一步，因此处理长程依赖比 RNN 更好。

## 示例讲解
查询 $q = (1, 0)$，键 $k_1 = (1,0),\ k_2 = (0,1),\ k_3 = (1,1)$，值 $v_1 = (1,0),\ v_2 = (0,1),\ v_3 = (2,2)$。

点积分数：$e = (1, 0, 1)$。Softmax：$e^1 = 2.718$，$e^0 = 1$；和 $= 6.437$，所以 $\alpha = (0.422, 0.155, 0.422)$。

上下文 $= 0.422\,(1,0) + 0.155\,(0,1) + 0.422\,(2,2) = (0.422 + 0.845,\ 0.155 + 0.845) = (1.267,\ 1.000)$。

屏蔽位置 3，把它的分数设为 $-\infty$：$\alpha = (2.718, 1)/3.718 = (0.731, 0.269, 0)$，上下文变为 $(0.731, 0.269)$。
