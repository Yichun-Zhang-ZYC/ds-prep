## 为什么重要
利益相关方和监管机构会问网络为什么做出某个预测，调试时往往也需要同样的答案（模型是在看水印，还是在看肿瘤？）。面试官会考察你是否了解主要的归因方法、它们的失效模式，以及“注意力并不自动等于解释”这一论断。表格数据的 SHAP/LIME 见 ML 课程；本课针对深度网络。

## 概念
**基于梯度的归因**（哪些输入特征最能改变输出）
- **显著性（Saliency）**：$|\partial f / \partial x_i|$。计算便宜，但有噪声且是局部的；饱和单元即使输入很重要，梯度也为零。
- **梯度 $\times$ 输入**：$x_i \, \partial f/\partial x_i$。考虑了特征的大小。
- **SmoothGrad**：对输入加噪后的多份副本的显著性取平均，以降低噪声。
- **积分梯度（IG）**：沿着从**基线** $x'$ 到 $x$ 的直线路径对梯度积分：
$$\text{IG}_i = (x_i - x_i')\int_0^1 \frac{\partial f(x' + \alpha(x - x'))}{\partial x_i}\,d\alpha$$
用黎曼和近似（20 到 300 步）。**完备性**：$\sum_i \text{IG}_i = f(x) - f(x')$，这也能告诉你步数是否足够。结果取决于基线（黑图、零向量、模糊图、平均嵌入）。
- **Grad-CAM**（CNN）：用类别得分的池化梯度对最后一层卷积特征图加权，得到粗粒度热力图。
- **扰动方法**：遮挡（把某个特征或图块替换为基线并测量下降量）、LIME、SHAP（Shapley 值；DeepSHAP/GradientSHAP 是近似）。与模型无关，但更慢且对基线敏感。

**注意力不（一定）是解释。**注意力权重显示的是某一层中信息被*路由*到哪里，但值向量和后续层会对其进行变换；不同的注意力分布可以给出相同的预测，而梯度或留一法重要性常与之不一致。更好的做法：**注意力 rollout/flow**（跨层相乘）或梯度加权注意力，并始终用干预来检验。

**探测（probing）**询问隐藏表示编码了什么：在冻结的激活上训练一个小的（通常是线性的）分类器来预测某种属性（词性、句法深度、棋局状态）。高准确率说明信息是*可解码*的，而不是模型*使用*了它。使用**控制任务**（随机标签），与随机初始化的基线比较，优先使用简单的探测器（或报告探测器复杂度）；用干预（激活修补、消融、引导）确认因果使用。

**相关内容**：概念激活向量（TCAV）、特征可视化，以及**机制可解释性**（电路、对激活训练的稀疏自编码器）。

**陷阱**：**合理性检验**（Adebayo 等）：如果随机化模型权重后解释几乎不变，那它只是在做边缘检测，并没有解释模型。忠实性（去掉归因最高的特征后输出是否改变？）不同于合理性（人看起来对不对？）。解释也不是关于现实世界的因果陈述。

## 示例讲解
取 $f(x) = x_0 x_1$，$x = (2, 3)$，基线 $x' = (0, 0)$，所以 $f(x) - f(x') = 6$。

- **梯度 $\times$ 输入**：$\nabla f = (x_1, x_0) = (3, 2)$，归因为 $(2 \cdot 3, 3 \cdot 2) = (6, 6)$，和为 $12$。由于特征交互，完备性不成立。
- **积分梯度**：沿路径 $x(\alpha) = \alpha x$，梯度为 $(3\alpha, 2\alpha)$。于是 $\text{IG}_0 = 2\int_0^1 3\alpha\,d\alpha = 3$，$\text{IG}_1 = 3\int_0^1 2\alpha\,d\alpha = 3$。和 $= 6 = f(x) - f(x')$：满足完备性，功劳在两个相互作用的特征间平均分配。
- **遮挡**（逐个把特征置零）：去掉任何一个特征都使输出下降 $6$，所以每个特征看起来都要对全部结果负责。

三种方法，三个答案：方法和基线的选择本身就是解释的一部分。
