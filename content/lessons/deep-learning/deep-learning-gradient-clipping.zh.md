## 为什么重要
梯度爆炸会导致损失尖峰和 NaN，在 RNN 和 Transformer 中尤其常见。裁剪是标准的防护措施，面试官会问按值裁剪与按范数裁剪的区别。

## 概念
**按全局范数裁剪**（标准做法）：计算所有梯度拼接后的 L2 范数 $\|g\| = \sqrt{\sum_k \|g_k\|^2}$，如果超过阈值 $c$，就对每个梯度重新缩放：
$$g \leftarrow g \cdot \min\!\left(1, \frac{c}{\|g\|}\right)$$
**方向保持不变**，只是限制了步长。在 PyTorch 中：`torch.nn.utils.clip_grad_norm_(params, max_norm=1.0)`，它同时返回裁剪前的范数。

**按值裁剪**：把每个分量限制在 $[-c, c]$。简单，但会改变梯度方向。

- **何时使用**：RNN/LSTM（最初的动机，Pascanu 等，2013）、Transformer（通常 `max_norm = 1.0`）、强化学习，以及偶尔出现损失尖峰（例如遇到坏批次）的训练。
- **在循环中的位置**：`loss.backward()`，然后**裁剪**，再 `optimizer.step()`。使用混合精度的损失缩放时，要**先反缩放**，否则裁剪的是被放大的梯度。
- **记录裁剪前的全局范数**。如果大多数步都被裁剪，说明阈值太低或学习率太高；范数出现尖峰通常预示着发散。
- **它不能解决梯度消失**，也不能替代合理的学习率、warmup 或良好的初始化。
- 使用 Adam 时更新大小大致对尺度不敏感，但裁剪仍然有帮助，因为它限制了单个尖峰对矩估计的污染。
- 在差分隐私 SGD 中，对每个样本的梯度裁剪（再加噪声）。

## 示例讲解
两个参数张量的梯度为 $g_1 = (3, 0)$ 和 $g_2 = (0, 4)$。全局范数 $= \sqrt{9 + 16} = 5$。阈值 $c = 1$。

**按范数**：缩放系数 $= 1/5 = 0.2$，得到 $g_1 = (0.6, 0)$ 和 $g_2 = (0, 0.8)$；新范数 $= 1$，各分量之间的比例不变。

**按值**，$c = 1$：$g_1 = (1, 0)$，$g_2 = (0, 1)$。此时两个张量的权重相同，与真实梯度的方向不同（真实梯度中 $g_2$ 是 $g_1$ 的 4/3 倍）。

如果范数是 0.5（低于 $c$），则不做任何改变。

> [!TIP] 面试技巧
> - 默认回答：按全局范数裁剪，阈值约 1.0，位置在 backward() 与 step() 之间。
> - 解释范数裁剪保持方向，而按值裁剪不保持。
> - 提到它针对的是梯度爆炸（而非消失），监控梯度范数是诊断手段。
