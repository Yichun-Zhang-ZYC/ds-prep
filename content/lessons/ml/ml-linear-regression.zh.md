## 为什么重要
线性回归是每个回归问题的基线，也是最常见的“推导一下 / 解释一下假设”类问题。面试官会追问假设、系数解释，以及会出什么问题（多重共线性、离群值、异方差）。

## 概念
模型：$y = X\beta + \varepsilon$。**普通最小二乘（OLS）**最小化残差平方和：

$$
\hat\beta = \arg\min_\beta \lVert y - X\beta \rVert^2 = (X^\top X)^{-1} X^\top y
$$

单个特征时：斜率 $\hat\beta_1 = \dfrac{\text{Cov}(x, y)}{\text{Var}(x)}$，截距 $\hat\beta_0 = \bar y - \hat\beta_1 \bar x$。

经典假设（LINE + 无多重共线性）：
- **线性（L）**：$E[y \mid x]$ 对参数是线性的（特征可以做变换：取对数、平方）。
- **独立（I）**：误差相互独立。
- **正态（N）**：误差服从正态分布；只有小样本下精确的 t 检验和区间才需要。
- **等方差（E）**（同方差性）。违反时 → 系数仍然无偏，但标准误是错的；使用稳健（HC）标准误。
- 无完全多重共线性。高度共线会放大系数的方差（检查 VIF），但对预测影响不大。

解释：$\beta_j$ = 在**其他特征保持不变**时，$x_j$ 增加一个单位，$y$ 的期望变化。除非实验设计支持，否则这是相关关系而不是因果关系。若用 $\log y$，$\beta_j \approx$ 相对（百分比）变化。

求解：维度小时用闭式解；规模大或病态时用梯度下降或基于 QR/SVD 的求解器。在高斯误差下，OLS 就是最大似然估计。平方损失使它对离群值敏感（可以考虑 Huber 损失）。

## 示例讲解
$x = [1, 2, 3, 4]$，$y = [2, 4, 5, 7]$。$\bar x = 2.5$，$\bar y = 4.5$。$\text{Cov} \propto \sum (x-\bar x)(y - \bar y) = 8$，$\sum (x - \bar x)^2 = 5$。斜率 $= 1.6$，截距 $= 4.5 - 1.6 \cdot 2.5 = 0.5$。拟合直线：$\hat y = 0.5 + 1.6x$。

> [!TIP] 面试技巧
> - 准备好推导正规方程：令梯度 $-2X^\top(y - X\beta)$ 等于 0。
> - 清楚哪些假设被违反会让系数有偏（遗漏变量、非线性），哪些只会破坏统计推断（异方差、非正态）。
> - 用“保持其他变量不变”来解释系数；除非有依据，否则避免使用因果性的措辞。
