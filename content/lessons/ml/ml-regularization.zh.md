## 为什么重要
“L1 和 L2 有什么区别？”“为什么 L1 会得到稀疏解？”是面试必考题。正则化是线性模型和神经网络中控制过拟合的主要工具。

## 概念
在损失函数中加上对权重大小的惩罚：

$$
\text{Ridge (L2): } \min_w \sum_i (y_i - x_i^\top w)^2 + \lambda \lVert w \rVert_2^2
\qquad
\text{Lasso (L1): } \min_w \sum_i (y_i - x_i^\top w)^2 + \lambda \lVert w \rVert_1
$$

- **L2（岭回归）**平滑地把所有权重向 0 收缩，但很少恰好为 0。能很好地处理相关特征（把权重分摊到它们之间）。有闭式解：$w = (X^\top X + \lambda I)^{-1} X^\top y$。
- **L1（Lasso）**会让部分权重**恰好变成 0**：自带特征选择。面对相关特征时，它往往随意挑一个。
- **Elastic Net** 把两者结合：$\lambda\big(\alpha \lVert w \rVert_1 + (1-\alpha) \lVert w \rVert_2^2\big)$。像 Lasso 一样稀疏，又像岭回归一样在相关特征组上保持稳定。

为什么 L1 是稀疏的：从几何上看，L1 约束区域是一个顶点落在坐标轴上的菱形，损失函数的等高线通常在顶点处与它相切，而顶点处有些坐标为 0。从梯度上看，无论权重多小，L1 惩罚都以恒定的力往 0 推；而 L2 的推力会随着权重变小而变小。

实践要点：先**标准化特征**（惩罚项依赖于尺度），不要惩罚截距，用交叉验证选择 $\lambda$。$\lambda$ 越大 → 偏差越大、方差越小。贝叶斯视角：L2 = 权重的高斯先验，L1 = 拉普拉斯先验。

## 示例讲解
一个特征、无截距，$X = [1, 2, 3]$，$y = [1, 2, 3]$。OLS 得到 $w = 14/14 = 1$。$\lambda = 14$ 的岭回归：$w = 14 / (14 + 14) = 0.5$。惩罚把权重减半。

> [!TIP] 面试技巧
> - 用一句话说出区别：L1 → 稀疏（特征选择），L2 → 权重小但非零，在相关特征上稳定。
> - 用菱形图或恒定梯度的论证来解释稀疏性。
> - 提到标准化、用交叉验证选 $\lambda$ 以及贝叶斯先验视角，都是加分项。
