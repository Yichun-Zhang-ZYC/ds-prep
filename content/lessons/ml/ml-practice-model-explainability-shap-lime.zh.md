## 为什么重要
监管方、产品团队和持怀疑态度的利益相关者会问“模型为什么这么说？”。面试官期望你能解释 SHAP 值究竟是什么、LIME 有何不同，以及两者都无法告诉你什么。全局工具（置换重要性、偏依赖）见“模型可解释性”；本课讲局部的、针对单次预测的解释。

## 概念
**Shapley 值**来自合作博弈论。把特征看作玩家，把预测看作收益。对特征 $i$：

$$\phi_i = \sum_{S \subseteq N\setminus\{i\}} \frac{|S|!\,(n-|S|-1)!}{n!}\,\big[v(S\cup\{i\}) - v(S)\big]$$

其中 $v(S)$ 是只有 $S$ 中的特征“已知”时的模型输出（其余特征在背景数据集上取平均）。它是特征 $i$ 在所有特征排列上的平均边际贡献。性质：
- **效率性**：$\sum_i \phi_i = f(x) - E[f(X)]$（各贡献之和等于预测减去基线）。
- 对称性、虚拟（从不改变输出的特征得 0）和可加性。它是唯一满足这些性质的归因方法。

**计算**：精确计算的成本为 $2^n$。**TreeSHAP** 对树集成模型是精确且多项式时间的；**KernelSHAP** 通过对采样联盟做加权回归来估计；神经网络用 **DeepSHAP** / 积分梯度。分类器的 SHAP 值通常以对数几率为单位。全局重要性：各行 $\text{mean}|\phi_i|$。

**LIME**：在 $x$ 周围采样扰动，查询黑盒模型，按接近程度加权（例如 $e^{-d^2/2\sigma^2}$），拟合稀疏的加权线性模型，读取其系数。它只提供**局部保真度**。

| | SHAP | LIME |
|---|---|---|
| 保证 | 可加、一致，总和为 $f(x)-$基线 | 无；局部线性近似 |
| 稳定性 | 对树是确定性的 | 随采样和核宽度变化 |
| 成本 | 树模型快，kernel 版本较重 | 每个实例便宜 |

**陷阱**：
- 解释的是**模型**，而不是现实世界：较大的 $\phi$ 不是因果效应。
- **相关特征**：边际（干预式）SHAP 会评估不现实的特征组合；相关特征之间的功劳分配带有任意性。
- 基线很重要：“相对于平均客户”可能不是用户想要的比较对象。
- 解释可以暴露泄漏（可疑的头号特征），但也可能被操纵或误读；应用置换重要性和领域知识交叉验证。

## 示例讲解
一个信用模型预测某申请人的违约概率为 0.35；平均预测为 0.10。示意的 SHAP 值（概率尺度）：`debt_to_income` +0.18，`credit_score` +0.08，`age` +0.03，`income` −0.04。总和 $= 0.25 = 0.35 - 0.10$（效率性成立）。拒贷的主要理由是负债收入比过高。

两个特征的精确玩具计算：$v(\varnothing)=0.10$，$v(\{1\})=0.20$，$v(\{2\})=0.25$，$v(\{1,2\})=0.40$。特征 1 被先加入或后加入的权重各为 $1/2$：
$\phi_1 = \tfrac12(0.20-0.10) + \tfrac12(0.40-0.25) = 0.05 + 0.075 = 0.125$，
$\phi_2 = \tfrac12(0.25-0.10) + \tfrac12(0.40-0.20) = 0.075 + 0.10 = 0.175$。
验证：$0.125 + 0.175 = 0.30 = 0.40 - 0.10$。对于特征独立的线性模型 $f = w\cdot x + b$，这简化为 $\phi_i = w_i(x_i - E[x_i])$。

> [!TIP] 面试技巧
> - 说出效率性和基线：SHAP 值之和等于预测减去平均预测。
> - 对比：SHAP 有公理基础且可加；LIME 是可能不稳定的局部代理模型。
> - 提醒相关特征和对因果的过度解读；用置换重要性作交叉验证。
