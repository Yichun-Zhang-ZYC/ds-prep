## 为什么重要
每个分类指标都由混淆矩阵构建而来。面试官常常递给你一个混淆矩阵，让你计算指标，或者解释模型犯了哪些错误、这些错误给业务带来多大代价。

## 概念
对于二分类（行 = 实际，列 = 预测）：

| | 预测为正 | 预测为负 |
|---|---|---|
| **实际为正** | TP（真阳性） | FN（假阴性，第二类错误） |
| **实际为负** | FP（假阳性，第一类错误） | TN（真阴性） |

派生比率：
- 召回率 / TPR / 灵敏度 $= TP/(TP + FN)$
- 特异度 / TNR $= TN/(TN + FP)$
- FPR $= FP/(FP + TN) = 1 -$ 特异度
- 精确率 / PPV $= TP/(TP + FP)$；NPV $= TN/(TN + FN)$

对于 $K$ 个类别，它是一个 $K \times K$ 矩阵：对角线是正确的预测，非对角线单元格显示**哪些类别被混淆**（例如数字识别中的 “3” 和 “8”），这能指导数据收集和特征工作。

为每个单元格赋予**代价**来评估业务影响：期望代价 $= c_{FP}\cdot FP + c_{FN}\cdot FN$。按行归一化（按实际类别）显示每类的召回率；按列归一化显示每类的精确率。

## 示例讲解
1,000 个用户上的流失模型：TP = 80，FN = 20，FP = 120，TN = 780。召回率 = 0.80，精确率 = 80/200 = 0.40，FPR = 120/900 ≈ 0.13。如果一次挽留优惠花费 \$10，挽回一个流失用户价值 \$100（假设每个被触达的流失用户都能挽回），净价值 = 80·100 − 200·10 = \$6,000，所以尽管精确率只有 40%，这个模型仍然值得使用。

> [!TIP] 面试技巧
> - 计算任何东西之前，先画出 2×2 的格子并标好 TP/FP/FN/TN；这能防止搞混。
> - 把单元格换算成业务代价；这样指标就变成了决策。
> - 对于多分类，指出哪些类别被混淆，以及你会怎么处理。
