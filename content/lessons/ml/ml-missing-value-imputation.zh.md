---

## 为什么重要
真实数据总有缺口。面试官想听到你先问值**为什么**缺失，再选择一种不会让模型产生偏差、也不会泄漏信息的策略。

## 概念
缺失机制：
- **MCAR**（完全随机缺失）：与任何因素都无关。删除行会损失数据，但不会带来偏差。
- **MAR**（随机缺失）：取决于已观测的变量（年龄大的用户会跳过收入字段）。利用这些变量做基于模型的填补是有效的。
- **MNAR**（非随机缺失）：取决于缺失值本身（高收入者隐瞒收入）。最难处理；缺失本身就带有信息。

策略：
- **删除**行（若很少且属于 MCAR）或列（若大部分为空且不重要）。
- **简单填补**：均值（对偏态敏感）、**中位数**（稳健）、类别变量用众数，或用常量如 “Unknown”。
- **加一个缺失指示列**：让模型学到“缺失”本身带有信号（往往是收益最大的一招，尤其对 MNAR）。
- **基于模型**：k-NN 填补、迭代填补（MICE：轮流用其他特征回归每个特征）。
- **时间序列**：前向填充、插值，但绝不能用未来的值来填补。
- **原生处理**：XGBoost / LightGBM 会为缺失值学习一个默认的划分方向。

规则：**只在训练数据上**拟合填补器；均值填补会缩小方差、削弱相关性，所以在推断分析中要小心（那时多重插补是严谨的选择）。

## 示例讲解
收入列：[40, 55, 缺失, 60, 1,000, 缺失]（单位：千）。观测值的均值 = 288.75，被 1,000 这个离群值扭曲了；中位数 = 57.5。用 57.5 填补，并加上 `income_missing = [0, 0, 1, 0, 0, 1]`，这样模型仍然能发现不填报的人是否有不同的行为。

> [!TIP] 面试技巧
> - 先问“为什么会缺失？”，并说出 MCAR / MAR / MNAR。
> - 中位数 + 缺失指示列是强大而简单的默认方案；提到提升树能原生处理 NaN。
> - 只在训练数据上拟合填补器，并且绝不用未来数据做前向填充。
