## 为什么重要
模型会随世界变化而衰减，但手动再训练无法扩展到多个模型。面试官会问：什么时候该再训练、由什么触发，以及如何防止糟糕的再训练结果上线。

## 概念
**再训练触发条件**（通常组合使用）：
- **定时**：固定周期（每天、每周）。简单可预测；没有变化时浪费，出问题时又太慢。
- **基于漂移**：输入或预测漂移（PSI、KS）超过阈值。无需标签。
- **基于性能**：线上指标（标签到达后）比基线低超过容忍度。
- **基于数据**：累积了足够多的新标注数据，或接入了新的数据源。

**自动再训练流水线**就是由编排器运行的普通 ML 流水线：拉取新快照 → 校验数据 → 构建特征 → 训练 → 评估 → 注册 → 受控晋升。
- **冠军-挑战者门禁（champion-challenger gate）**：在*同一个*近期留出集上评估新模型与当前线上模型；只有超过冠军且幅度大于噪声时才晋升。
- **安全发布**：晋升后的模型仍需经过 shadow/canary 才能接管全部流量，旧版本保留在 registry 中以便回滚。
- **护栏**：冷却期（两次再训练的最小间隔）、数据校验失败则中止运行、算力预算，高风险模型需人工审批。

**陷阱**：用模型自身决策产生的数据再训练会形成**反馈回路**；标签延迟意味着最新的数据没有标签；如果漂移由上游 bug 引起，再训练只会把 bug 固化进模型。

## 示例讲解
某欺诈模型每周再训练（定时），并且在主要特征的 PSI 超过 0.2（漂移）时也会再训练。一次再训练后，冠军模型在上周留出集上的 AUC 为 0.912，挑战者为 0.915，提升 0.003，低于要求的 0.005 余量，因此**不**晋升（提升在噪声范围内）。下一次再训练得分 0.921 > 0.912 + 0.005 = 0.917，于是注册为 `staging` 并进入 5% 的 canary。

```python-exercise
  "hints": ["冷却期检查放在最前面，这样噪声信号不会触发连续的再训练。", "promote 比较的是挑战者与 champion + margin，而不是只与 champion 比较。"]
}
```

> [!TIP] 面试技巧
> - 说出触发类型（定时、漂移、性能、数据），并说明会配合冷却期组合使用。
> - 晋升前务必在同一留出集上做冠军-挑战者比较，然后再 canary/shadow。
> - 提到训练前校验和反馈回路：盲目地用坏数据或自身生成的数据再训练只会更糟。
