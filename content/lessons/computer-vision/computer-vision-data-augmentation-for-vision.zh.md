## 为什么重要
数据增强是视觉任务中最便宜的准确率与鲁棒性来源，它编码了你对不变性的假设。面试官会考察你是否知道哪些变换对哪种任务是安全的、混合类方法如何工作，以及检测、分割和自监督学习中的增强有何不同。

## 概念
**原则**：对训练图像施加不改变标签的变换，使模型看到每个样本的许多合理变体。它既是正则化手段，也是注入任务已知**不变性**（平移、尺度、颜色）的方式。随机增强**只用于训练**；验证和测试使用确定性的缩放/中心裁剪。训练配方参见《图像分类》。

**类别**
- **几何类**：翻转、**RandomResizedCrop**（随机面积 8-100%、长宽比 3/4-4/3）、旋转、仿射、透视。
- **光度类**：亮度/对比度/饱和度/色相抖动、灰度化、高斯模糊、噪声、JPEG 压缩，以及模拟目标相机。
- **遮挡类**：Cutout / 随机擦除丢掉一块区域，使模型不能依赖某个局部。
- **混合类**：**Mixup** 混合两张图像及其标签，$\tilde x = \lambda x_a + (1-\lambda)x_b$，$\tilde y = \lambda y_a + (1-\lambda)y_b$，其中 $\lambda \sim \text{Beta}(\alpha,\alpha)$。**CutMix** 从 $x_b$ 粘贴一块，并把 $\lambda$ 设为**剩余面积占比**，使标签与可见像素成正比。**Mosaic**（YOLO）把四张图拼在一起，暴露小目标和多样的上下文。
- **学习得到的策略**：AutoAugment 用强化学习搜索策略；**RandAugment** 只有两个旋钮（操作个数 $N$、共享幅度 $M$）；TrivialAugment 每张图随机采样一个操作和幅度，无需调参。现代 ViT 的强力配方组合了 RandAugment、Mixup/CutMix、随机擦除、标签平滑和随机深度。
- **生成式 / 合成**：把物体复制粘贴到新背景、扩散模型或仿真器图像；注意域差距，且绝不能把合成图像泄露到评估集中。

**任务特定规则**
- **检测 / 分割**：框和掩码要与像素**一起**变换（翻转会镜像框的 x 坐标；裁剪会裁掉框并丢弃大部分在外面的框，保留一个最小可见比例）；掩码用最近邻插值。
- **自监督**（SimCLR、DINO）：同一图像的两个强增强视图（裁剪 + 颜色抖动 + 模糊）定义正样本；增强本身*就是*监督信号。
- **测试时增强（TTA）**：对翻转/裁剪后的预测取平均，以数倍的推理成本换取小幅准确率提升。

**安全检查：它保持标签不变吗？** 水平翻转对文字、数字（旋转下的 6/9）、交通标志以及左右有意义的解剖结构是错误的；颜色是信号时（成熟度、染色切片）强烈的颜色抖动有害；垂直翻转对卫星图像可以，但对街景不行。要问清部署相机会出现哪些真实变化。

**工程**：增强常常是数据加载的瓶颈，因此要增加 worker、使用 GPU 流水线（DALI、Kornia），并记录增强后的样本进行**目视检查**。数据增强无法修复标签噪声或采集时的分布偏移。

## 示例讲解
对 $224 \times 224$ 图像做 CutMix，采样 $\lambda = 0.7$。粘贴框的面积占比为 $1-\lambda = 0.3$，边长比为 $\sqrt{0.3} \approx 0.548$，边长 $\lfloor 224 \times 0.548 \rfloor = 122$ 像素。以 $(112, 112)$ 为中心时，两个坐标轴上都覆盖 $[51, 173)$。实际粘贴面积是 $50{,}176$ 个像素中的 $122^2 = 14{,}884$，因此标签权重重新计算为 $\lambda_{adj} = 1 - 0.2966 = 0.7034$：目标 $= 0.7034\,y_a + 0.2966\,y_b$。如果框的中心在角落，就会被裁剪，$\lambda_{adj}$ 必须依据裁剪后的面积重算，这就是各种实现总在裁剪后调整 $\lambda$ 的原因。

对 100 像素宽图像中的框 $(10, 20, 50, 60)$ 做水平翻转，得到 $(100-50, 20, 100-10, 60) = (50, 20, 90, 60)$：注意 x 坐标的角色互换，以保证 $x_1 < x_2$ 仍然成立。

> [!TIP] 面试技巧
> - 把数据增强看作对不变性的编码；对每个变换都问它在这个任务上是否保持标签。
> - 解释 Mixup 与 CutMix 的区别，以及 CutMix 为什么按可见面积重新分配标签；提到 RandAugment 是只有两个参数的策略。
> - 对检测/分割要说明框和掩码必须随图像一起变换；对自监督来说增强定义了正样本。
> - 提到检查样本、用 GPU 增强提升吞吐，以及 TTA 及其推理成本。
