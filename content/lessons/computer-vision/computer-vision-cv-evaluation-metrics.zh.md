## 为什么重要
检测和分割不能用简单的准确率打分：一个预测既有类别又有位置，而且重复预测也有影响。mAP 是论文和基准测试中的核心数字，面试官希望你能手算它，并解释 COCO 与 VOC 的约定。

## 概念
**IoU**（Jaccard）$= \dfrac{|A \cap B|}{|A \cup B|}$ 衡量框或掩码的重叠程度。如果检测的类别正确，且与某个未匹配真值框的 IoU $\ge$ 阈值（VOC / AP50 为 0.5），则它是**真正例（TP）**。与已匹配框重复的检测和低 IoU 的框是**假正例（FP）**；未被匹配的真值框是**假负例（FN）**。真负例没有定义，所以没有准确率。

**对一个类别在一个 IoU 阈值下计算 AP**
1. 把所有检测按置信度降序排序。
2. 贪心地标记每个为 TP 或 FP（每个真值框只能被匹配一次）。
3. 累计的 TP/FP 给出每个排名处的 precision $= TP/(TP + FP)$ 和 recall $= TP/\text{num\_gt}$，描出**精确率-召回率曲线**。
4. 使 precision 单调：$p_{\text{interp}}(r) = \max_{r' \ge r} p(r')$。
5. **AP** = 插值曲线下的面积，$\sum_k (r_k - r_{k-1})\, p_{\text{interp}}(r_k)$（全点法，VOC 2010+）。COCO 使用 101 个召回点。

**mAP** 对各类别的 AP 取平均。**COCO mAP**（记为“AP”）还会对 IoU 阈值 $0.5, 0.55, \dots, 0.95$ 取平均，因此奖励精确定位；AP50 和 AP75 分别是宽松和严格的切片，APs/APm/APl 按目标大小划分。AR 衡量每张图固定检测数下的召回率。除精度外，还应报告 FPS/延迟和模型大小。

**其他任务**
- 分类：top-1/top-5、各类别 precision/recall/F1、混淆矩阵（类别不平衡时区分 macro 与 micro 平均）。
- 分割：IoU、Dice、**mIoU**；全景质量 PQ = 分割质量 x 识别质量。
- 深度：AbsRel、RMSE、$\delta < 1.25$。检索 / CLIP：recall@K。
- 注意：AP 依赖于 IoU 阈值和匹配规则；较低的置信度阈值不会损害 AP（曲线只是延长），但部署时需要从 PR 曲线选出具体的工作阈值。

## 示例讲解
类别“car”有 4 个真值框。按分数排序的五个检测依次是 TP、TP、FP、TP、FP。

| 排名 | TP/FP | precision | recall |
|---|---|---|---|
| 1 | TP | 1/1 = 1.00 | 0.25 |
| 2 | TP | 2/2 = 1.00 | 0.50 |
| 3 | FP | 2/3 = 0.67 | 0.50 |
| 4 | TP | 3/4 = 0.75 | 0.75 |
| 5 | FP | 3/5 = 0.60 | 0.75 |

插值后的 precision 为 $(1, 1, 0.75, 0.75, 0.60)$（取右侧最大值）。AP $= 0.25 \cdot 1 + 0.25 \cdot 1 + 0.25 \cdot 0.75 = 0.6875$。第四个真值框始终没有被找到，所以 recall 止步于 0.75，曲线其余部分贡献为 0。
