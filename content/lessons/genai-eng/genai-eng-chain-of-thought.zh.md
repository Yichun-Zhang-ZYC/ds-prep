---

## 为什么重要
“一步一步地思考”是最著名的提示词技巧，面试官想知道它为什么有效、什么时候无效，以及它如何用 token 和延迟换取准确率。它也是推理模型和 agent 的概念基础。

## 概念
**思维链（CoT）**提示让模型在给出最终答案之前先写出中间推理。自回归模型对每个 token 的计算量是固定的，所以额外的推理 token 为多步问题（算术、逻辑、规划）提供了更多计算和草稿空间。

变体：
- **Zero-shot CoT**：附加“Let's think step by step”（或“先推理，再给出 `Answer: ...`”）。
- **Few-shot CoT**：示范中包含完整的推理过程，而不仅仅是答案。
- **自洽性（Self-consistency）**：用 temperature $> 0$ 采样 $n$ 条推理路径，提取每条的最终答案，进行**多数投票**。成本随 $n$ 线性增长；在数学和逻辑基准上收益明显。
- **先规划再求解 / 问题分解**，以及对思路做树/图搜索，用于更难的问题。
- **推理模型**（o 系列、带 extended thinking 的 Claude、DeepSeek-R1）通过强化学习训练来生成长的内部推理。通常不需要让它们“一步一步思考”；直接给出目标和 token 或推理力度预算即可。

实践要点：
- **把推理和答案分开**，使用固定标记（`Answer: ...`）或结构化字段，便于解析。在 JSON schema 中把推理字段放在答案字段之前；如果答案在前，推理就帮不上它。
- **成本与延迟**：推理 token 按输出 token 计费（也就是更贵的那种），并且会推迟第一个有用 token 的出现。
- **并非总是有帮助**：简单的查找和某些模式匹配任务不会提升，甚至会变差；模型写出的理由不一定忠实反映其真实计算过程。
- 默认不要把原始思维链展示给终端用户；它可能出错、冗长，或泄露指令。

## 示例讲解
问题：钢笔每支 \$2，或 3 支 \$5。买 7 支最便宜是多少？

直接回答（常常出错）：“\$14”。使用 CoT：“3 支 \$5 比 3 支单买（\$6）更便宜。7 = 3 + 3 + 1，所以 2 个套装 = \$10，再加 1 支 = \$2。Answer: 12”。

用 5 个样本做自洽性，得到的最终答案为 12、12、14、12、14。多数投票返回 12，置信度 3/5 = 0.6。投票占比是一个粗略的置信度信号：一致性低时可以升级到更大的模型或交给人工。成本：5 个样本、每个约 150 个输出 token，输出成本约为单个样本的 5 倍。

> [!TIP] 面试技巧
> - 解释机制（更多 token 意味着更多计算和草稿空间）和代价（输出 token、延迟）。
> - 提到用自洽性提升准确率，以及推理模型作为手写“一步一步思考”的现代替代。
> - 陷阱：结构化输出中要先推理后回答；也不要把理由当作忠实的解释。
