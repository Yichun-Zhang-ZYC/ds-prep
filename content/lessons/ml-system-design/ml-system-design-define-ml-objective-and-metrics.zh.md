## 为什么重要
面试官希望看到你把**业务指标**（公司关心的）、**机器学习目标**（训练所用的）和**评估指标**（离线和在线）区分开。模型在损失上赢了、却没有改变产品任何指标，是最常见的失败案例。

## 概念
建立从业务到模型的链条：
1. **业务指标**：收入、留存、有价值的使用时长、欺诈损失。
2. **在线指标**：主要指标（A/B 测试据此决策）加上**护栏指标**（延迟、投诉、取消订阅、多样性、成本），护栏指标不能变差。
3. **机器学习目标**：可训练的代理目标，如点击、购买、观看时长或欺诈标签。要说明代理目标与真实目标之间的差距（点击会奖励标题党）。
4. **离线指标**：计算成本低且与在线指标相关。根据任务和类别不平衡情况选择。

**选择离线指标**
- 均衡分类：准确率、ROC-AUC。不平衡：PR-AUC、固定阈值下的精确率/召回率，以及按成本加权的指标。
- 排序/推荐：$\text{Precision@}k = \frac{\text{前 }k\text{ 个中相关的数量}}{k}$，$\text{Recall@}k = \frac{\text{前 }k\text{ 个中相关的数量}}{\text{全部相关的数量}}$，NDCG，MRR。用户只能看到 $k$ 个位置时用 Precision@k；候选召回阶段用 Recall@k。
- 下游使用概率（竞价、定价）：对数损失和校准。
- 回归：MAE（稳健）vs RMSE（惩罚大偏差）；成本不对称时考虑分位数损失。

**目标设计**：逐点（预测每个标签）、成对（排序成对样本）、列表级（直接优化整个列表）。有多个目标时，训练多个输出头再组合，例如 $\text{score} = P(\text{click}) \cdot E[\text{watch} \mid \text{click}]$，或在线调节的加权和。注意**标签泄漏**和**指标被刷**。

至少说出一个护栏指标，这体现产品意识。

## 示例讲解
视频信息流。业务目标：长期留存。目标 A：预测 $P(\text{click})$——简单、标签丰富，但会偏向标题党。目标 B：预测点击后的期望观看时长，并按 $P(\text{click}) \cdot E[\text{watch}]$ 排序。主要在线指标：每用户每周会话数；护栏指标：p99 延迟、“不感兴趣”比例、创作者多样性。

对一个前 5 的列表做离线检查：按排名顺序的相关性标签为 $[1, 0, 1, 1, 0]$，该用户共有 4 个相关视频（有一个没有展示）：
- Precision@3：前 3 个 = $[1,0,1]$ → $2/3 \approx 0.667$。
- Recall@3：$2/4 = 0.5$。
- Precision@5：$3/5 = 0.6$；Recall@5：$3/4 = 0.75$。

> [!TIP] 面试技巧
> - 画出这条链：业务指标 → 在线指标（含护栏）→ 机器学习目标 → 离线指标。
> - 明确指出代理目标的差距（点击 vs 满意度）以及如何缓解。
> - 根据类别不平衡程度和用户看到的内容选指标（可见列表用 Precision@k，召回阶段用 Recall@k）。
