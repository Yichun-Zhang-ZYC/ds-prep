## 为什么重要
离线评估是在昂贵的 A/B 测试之前快速、廉价的过滤器。面试官会检查你是否在无泄漏的情况下划分数据、选择与任务匹配的指标、查看分片和不确定性，以及是否知道离线收益为什么常常无法迁移到线上。

## 概念
**数据划分**
- 对任何带时间或反馈回路的问题使用**时间划分**（用过去训练，用未来验证和测试）。随机划分会泄漏。
- 当实体重复出现时，按用户/会话/商户做**分组划分**，使测试集中的实体是未见过的。
- 保留一个从未触碰的最终**测试集**；在验证集上调参。数据量小时使用（时间序列/分组）交叉验证。
- 与线上服务保持一致：相同的候选集、特征和延迟。

**按任务选择指标**
- 分类：PR-AUC、操作阈值下的精确率/召回率、按成本加权的指标、校准。
- 排序：带分级增益的 NDCG@k，$\text{DCG@}k = \sum_{i=1}^{k} \frac{2^{rel_i} - 1}{\log_2(i+1)}$ 且 $\text{NDCG@}k = \text{DCG@}k / \text{IDCG@}k$；召回阶段还有 MRR、MAP、Recall@k。
- 回归/预测：MAE、RMSE、MAPE/sMAPE、分位数损失。

**不要只看一个数字**
- **分片**：按国家、新用户 vs 老用户、设备、物品热度（头部 vs 长尾）。平均收益可能掩盖关键人群上的退化。
- **不确定性**：自助法（bootstrap）置信区间；忽略小于噪声的收益。
- **错误分析**：检查最严重的错误并聚类。
- **鲁棒性**：压力测试、对抗或边缘案例、跨群体的公平性指标。

**离线与在线为何不同**：反馈回路和位置偏差（日志反映的是旧模型）、用户行为变化、延迟影响，以及指标只是代理。对于策略变更，在随机化日志上使用**反事实估计器**（逆倾向评分、双重稳健）。把离线结果当作门槛，把 A/B 测试当作真相。

## 示例讲解
对 3 个物品的排序，相关性分级为 0-3。模型的排序对应的真实相关性是 $[2, 3, 0]$；理想顺序是 $[3, 2, 0]$。
- DCG@3 $= \frac{2^2-1}{\log_2 2} + \frac{2^3-1}{\log_2 3} + 0 = 3 + \frac{7}{1.585} \approx 3 + 4.417 = 7.417$。
- IDCG@3 $= \frac{7}{1} + \frac{3}{1.585} \approx 7 + 1.893 = 8.893$。
- NDCG@3 $\approx 7.417/8.893 = 0.834$。

分片：总体准确率 91% 看起来不错，但新用户（占流量 10%）只有 78%，老用户为 92.4%：$0.1 \times 78 + 0.9 \times 92.4 = 90.96$。冷启动人群才是被平均数掩盖的问题。

> [!TIP] 面试技巧
> - 先说“按时间划分，并按用户分组”；这表明你懂得泄漏问题。
> - 报告分片结果和置信区间，而不只是一个总体数字。
> - 解释离线为何会误导（曝光偏差、反馈回路），并说明 A/B 测试才是最终裁判。
