## 为什么重要
企业搜索（在网盘、wiki、工单、邮件中找到正确的文档）是一个带有苛刻附加条件的检索问题：按用户的权限、众多异构数据源、稀少的点击数据以及紧张的基础设施预算。它是 RAG 问题中非生成的那一半，所以面试官借此看你能否在不依赖 LLM 的情况下，就检索质量、安全和规模进行推理。

## 概念
**范围**：输入 = 一个简短查询（“Q3 安全评审”、“error E1042”），输出 = 带摘要片段的文档排序列表，而不是生成的答案。若要在其上做生成，参见*企业问答 RAG 聊天机器人*；通用的漏斗和 LTR 参见*搜索排序*。本课深入讲公司内部有何不同。

**有何不同**：
- **权限**：用户绝不能看到自己无权打开的文档，而且 ACL 每天都在变化。
- **异构性**：幻灯片、PDF、wiki 页面、聊天线程、工单；每种都需要自己的解析器和信号（作者、新近度、浏览量）。
- **反馈稀疏**：用户少、每个查询的点击少，所以不要只依赖基于点击训练的排序器。
- **意图混合**：导航型（“福利页面”）、精确词查找（错误码、工单号）和探索性语义查询。

**架构**：
1. *摄取*：带增量同步和删除标记（tombstone）的连接器，版面感知解析，对近乎相同的副本去重，按结构切块并在每个块前加上标题/路径。同时存储**文档级和块级**记录；通过聚合块分数（取最大值，或最大值加上多处命中的小幅加成）来对文档排序。
2. *索引*：BM25 倒排索引和稠密索引（嵌入模型 + HNSW 或 IVF-PQ），两者都带有 ACL 和元数据字段。
3. *查询路径*：查询理解（用公司术语表展开缩写、拼写纠错、意图），**混合召回**（BM25 抓住精确 ID 和稀有词；稠密抓住同义改写），用 RRF 融合，然后对前约 50-100 个结果用 cross-encoder 或 LTR 重排器，使用文本相关性加上新近度、热度、作者/团队亲和度和来源类型。
4. *摘要与界面*：高亮最匹配的块，显示来源和日期。

**访问控制**：标准设计是**索引内权限过滤**（每个块一个位图或允许的主体列表，在查询时与用户所属的组匹配）。对 top-$K$ 结果做后过滤很简单，但当大多数命中都被禁止时可能返回过少结果，迫使过度获取；对 ANN 做前过滤可能损害召回和速度，所以使用感知过滤的 HNSW 遍历，或按租户/部门划分索引。快速传播 ACL 变更（事件驱动，仅重新索引 ACL 字段），同步出错时按“拒绝”处理（fail closed）。

**嵌入模型**：先用强大的通用模型，再用领域数据对进行适配：LLM 为每个块生成的合成查询、来自近似块的困难负例，之后再用点击或改写数据。Matryoshka 嵌入以及 int8/二值量化能以很小的召回损失减少内存；用全精度向量对候选**重打分**。

**评估**：很少有标签，所以要自举：LLM 生成的问题-块配对加上几百条经人工判定的真实查询；衡量 recall@K（召回）和 NDCG@10（排序），按来源和查询类型切分。线上：点击率、成功率（带停留的点击或没有改写）、零结果率、首次点击时间、延迟。用对抗性测试检查权限正确性（用户绝不能检索到被禁止的文档）。

**运维**：新鲜度 SLO（新文档在几分钟内可搜），更换嵌入模型时（需要全量重新嵌入）做索引版本化的蓝绿重建，SaaS 场景下按租户隔离，审计日志，PII 处理。

## 示例讲解
容量估算（仅作说明）。2000 万文档，每个 8 个块，共 1.6 亿个向量。嵌入维度为 1024。

- float32：每个向量 $1024\times4=4096$ 字节，所以 $160\text{M}\times4096\approx655$ GB。
- int8 量化：1024 字节，约 $164$ GB。
- HNSW 图的链接每个向量约 128 字节，增加约 $20$ GB。

所以 int8 加图约 $184$ GB 驻留内存，全精度向量放在 SSD 上用于重打分。使用 64 GB 节点，并为操作系统、查询和增长预留 50% 余量（可用 32 GB），则需要 $\lceil184/32\rceil=6$ 个分片，各分片并行查询并合并结果。

权限过滤：如果用户只能看到 20% 的语料而你做后过滤，要得到 $K=10$ 个结果平均需要约 $10/0.2=50$ 个候选，加上 1.5 倍安全系数以应对波动则为 75。如果 ACL 限制严格得多（1%），后过滤就会失效，因此要把过滤下推到索引内。

> [!TIP] 面试技巧
> - 先讲权限：这是与网页搜索最大的区别，也表明你有实际经验。
> - 解释为什么混合召回优于单独使用任一种，以及重排器所处的位置。
> - 做估算：向量数 x 维度 x 字节数，再讲量化和分片。
> - 回应标签冷启动：合成查询、小规模人工金标准集，之后是经偏差校正的点击。
