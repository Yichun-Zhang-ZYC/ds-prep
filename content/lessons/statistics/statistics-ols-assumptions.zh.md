## 为什么重要
“线性回归有哪些假设？违反了会怎样？”是最常见的 DS 面试题之一。好的回答会区分两类假设：保证系数无偏所需的假设，以及保证标准误有效所需的假设。

## 概念
模型：$y = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p + \varepsilon$。OLS 选取使 $\sum (y_i - \hat y_i)^2$ 最小的 β。

| 假设 | 违反后的后果 |
|---|---|
| 参数上的**线性** | 拟合有偏；加入新项 / 做变换 |
| **没有完全多重共线性** | 系数无法识别；接近共线时系数不稳定 |
| **外生性**：$E[\varepsilon \mid X] = 0$（没有遗漏的混杂变量） | 系数**有偏**，这是最严重的问题 |
| **误差相互独立** | 标准误偏小（聚集数据 / 时间序列数据） |
| **同方差**：误差方差恒定 | 标准误不正确；使用稳健（HC）标准误 |
| **误差正态** | 只影响小样本推断；大样本有中心极限定理兜底 |

在前四条（加上同方差）成立时，OLS 是 **BLUE**：最佳线性无偏估计量（高斯–马尔可夫定理）。

## 示例讲解
在各城市之间用广告投入对销售额做回归：

- 大城市的广告投入**和**销售额都更高，但销售额高还有其他原因 → 遗漏变量（城市规模）使广告系数向上偏。解决办法：把人口作为控制变量加入，或者做实验。
- 残差的离散程度随城市规模增大 → 异方差 → 使用稳健标准误。
- 每个城市有每周的数据 → 同一城市内误差相关 → 按城市做聚类标准误。

> [!TIP] 面试技巧
> - 按后果的严重程度给假设排序：先讲外生性（偏差），再讲误差结构（标准误），最后讲正态性。
> - 为每一条说出对策：控制变量或实验、稳健 / 聚类标准误、变量变换。
> - 提到诊断方法：残差对拟合值图、Q-Q 图、VIF。
